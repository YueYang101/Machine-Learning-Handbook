基本定理：四件反复出现的工具
贝叶斯变换 · 马尔科夫性质（与 POMDP）· Bellman 最优性原则 · 高斯的 ∝exp 形式

这一页不讲任何具体算法，只把会在别的笔记里反复被调用的四件工具集中放好，并且每一条都写清楚「它在哪里被用到」。Diffusion Policy 的推导用了 ①②④，PPO 学习路线用了 ②③，POMDP 那一节解释了为什么灵巧手任务里要给策略喂 history。

①贝叶斯变换：把「因果方向」倒过来

$$P(A\mid B)=\frac{P(B\mid A)\,P(A)}{P(B)} \qquad\Longleftrightarrow\qquad \text{后验}=\frac{\text{似然}\times\text{先验}}{\text{证据}}$$ $$\text{Posterior}=\frac{\text{Likelihood}\times\text{Prior}}{\text{Evidence}}$$

四个名字各自的含义，用一句话对齐：

项读法在推导里的角色
先验 $P(A)$看到证据之前，我认为 $A$ 有多可能通常是我们自己设定的模型假设
似然 $P(B\mid A)$如果 $A$ 成立，观测到 $B$ 的可能性正向的、容易写出来的那个方向
证据 $P(B)$不管 $A$ 是什么，$B$ 本身的总概率归一化常数，比较形状时常整个扔掉
后验 $P(A\mid B)$看到 $B$ 之后，对 $A$ 的更新真正想要、但难直接写的那个方向
它的全部价值：把难写的方向换成好写的方向。很多问题里「反向」是你要的、「正向」是你能写的。贝叶斯就是这两者之间的兑换公式。分母 $P(B)$ 不含 $A$，所以只要不需要绝对数值、只需要比较 $A$ 的不同取值谁更可能，就可以写成 $$P(A\mid B)\;\propto\;P(B\mid A)\,P(A)$$ ——这个「$\propto$ 写法」是后面工具 ④ 的入场券。
用在哪：Diffusion Policy §9——正向加噪 $q(x_k\mid x_{k-1})$ 好写（是我们自己设计的），但生成需要的是反向 $q(x_{k-1}\mid x_k)$。贝叶斯把它翻过来，配合工具 ④ 直接读出一个高斯。§10.8 里把 loss 中每一项的分子从正向翻成反向，用的也是同一招。

②马尔科夫性质：知道现在，就不必知道过去

$$P\big(s_{t+1}\mid s_0,s_1,\cdots,s_t\big)=P\big(s_{t+1}\mid s_t\big)$$

带上动作的版本（RL 里真正用的那个）：

$$P\big(s_{t+1}\mid s_0,a_0,\cdots,s_t,a_t\big)=P\big(s_{t+1}\mid s_t,a_t\big)$$
它不是宇宙真理，是建模时主动选的假设。同一个物理系统，$s_t$ 写法不同，马尔科夫性质可能成立也可能不成立。经典例子：只用「位置」当 state，小球的运动不是马尔科夫的（同一位置可能在上升也可能在下落）；把 state 改成「位置 + 速度」，它就是马尔科夫的了。所以「这个问题满不满足马尔科夫」这句话本身是不完整的——必须先说清 state 怎么定义。工程上遇到「策略学不动、行为看起来精神分裂」，第一件该怀疑的事往往就是 state 漏了关键量。
用在哪：① PPO 学习路线——整个 MDP 框架建立在它上面，没有它就没有「只看当前 state 决策」的 policy $\pi(a\mid s)$，也没有 Bellman 递归。② Diffusion Policy §8–§10——正向加噪链是按它构造的，所以 $q(x_{1:T}\mid x_0)=\prod_k q(x_k\mid x_{k-1})$ 能拆开；§10.8 里 $q(x_k\mid x_{k-1})=q(x_k\mid x_{k-1},x_0)$ 这个「白挂一个条件」的动作，靠的也是它。

②′POMDP：当 state 看不全的时候

现实里我们常常拿不到真正的 $s_t$，只能拿到一个观测 $o_t$。此时问题从 MDP 变成 POMDP（Partially Observable Markov Decision Process，部分可观测马尔可夫决策过程）：

MDPPOMDP
手上有什么真实 state $s_t$观测 $o_t\sim O(\cdot\mid s_t)$，$s_t$ 不可见
马尔科夫性对 $s_t$ 成立对 $o_t$ 不成立
策略输入$\pi(a\mid s_t)$ 就够要 $\pi(a\mid o_{0:t},a_{0:t-1})$，或对 belief $b_t=P(s_t\mid\text{history})$ 决策
实现手段MLP 直接吃 state喂一段 history（frame stacking）、上 RNN/Transformer，或显式估计 belief
关键洞察：POMDP 对 belief state 恢复了马尔科夫性。$b_t$ 是「在看过全部历史之后，我认为真实 state 的概率分布」，它的更新恰好是一次贝叶斯：$b_{t+1}\propto O(o_{t+1}\mid s')\sum_s P(s'\mid s,a_t)\,b_t(s)$。也就是说 POMDP 是「belief 空间上的 MDP」——代价是这个空间是连续的、维度极高，所以实践中几乎都用「喂 history 让网络自己学一个隐式 belief」来近似。
用在哪：灵巧手任务是典型 POMDP——物体质量、摩擦系数、内部惯量都观测不到，但会决定该用多大力。这就是 PPO 局限与变体那页里「未知参数需要 history」以及 RMA / 域随机化 + adaptation 一类方法的根源：不是策略不够强，是 state 本来就不完整。

③Bellman 最优性原则：最优的尾巴还是最优的

一条最优策略的剩余部分，从任何中间状态开始，也必须仍然是最优的。
为什么这条原则这么重要：它把「在所有轨迹上做优化」变成「一步一步递推」。没有它，求最优策略就得枚举指数多条轨迹；有了它，可以写成递归——这就是 Bellman 方程： $$V^\pi(s)=\mathbb E_{a\sim\pi,\,s'\sim P}\big[r(s,a)+\gamma V^\pi(s')\big]$$ $$V^*(s)=\max_a\;\mathbb E_{s'}\big[r(s,a)+\gamma V^*(s')\big],\qquad Q^*(s,a)=\mathbb E_{s'}\Big[r(s,a)+\gamma\max_{a'}Q^*(s',a')\Big]$$ 「当前一步的即时 reward + 剩下那段的最优值」——右边那个 $V^*(s')$ 之所以能直接写成「最优值」，靠的正是最优子结构。动态规划、value iteration、Q-learning、TD、Actor-Critic 的 critic，全部建立在这一条上。
用在哪：PPO 学习路线 Stage 2 起的全部内容——Value / Q / Policy Evaluation / Policy Improvement / TD error / GAE，都是这条原则的展开。它同时也依赖 马尔科夫性质：递归之所以只需要 $s'$ 而不需要整条历史，正因为 $s'$ 已经是充分的。

④高斯的 $\propto\exp$ 形式：把配方法当成读数器

$$p(x)=\frac{1}{\sqrt{2\pi\sigma^2}}\exp\!\left(-\frac{(x-\mu)^2}{2\sigma^2}\right) \qquad\Longrightarrow\qquad \mathcal N(x;\mu,\sigma^2)\;\propto\;\exp\!\left(-\frac{(x-\mu)^2}{2\sigma^2}\right)$$

归一化常数 $\frac{1}{\sqrt{2\pi\sigma^2}}$ 不含 $x$，所以在「比较形状 / 求某个 $x$ 的条件分布」时可以整个扔掉。但真正好用的是反过来读：

$$\exp\!\Big(-\tfrac12\big(Ax^2-2Bx\big)+\text{与 }x\text{ 无关的项}\Big) \;\Longrightarrow\; x\sim\mathcal N\!\left(\frac BA,\;\frac1A\right)$$

也就是说：任何能整理成「$x$ 的二次型的负指数」的表达式，必然是一个高斯，而且把它按 $x^2$ 和 $x$ 的系数配平之后，均值和方差可以直接读出来，完全不需要做积分。

验证一下这个读数规则：把 $\mathcal N(\mu,\sigma^2)$ 的指数展开，

$$-\frac{(x-\mu)^2}{2\sigma^2}=-\frac12\left(\frac{1}{\sigma^2}x^2-2\cdot\frac{\mu}{\sigma^2}x\right)+\text{const} \;\Longrightarrow\;A=\frac1{\sigma^2},\;B=\frac{\mu}{\sigma^2} \;\Longrightarrow\;\frac1A=\sigma^2,\;\frac BA=\mu\;\checkmark$$
用在哪：Diffusion Policy §9 的核心一步——把三个高斯（正向单步、两个闭式解）的指数加加减减，整理成 $x_{k-1}$ 的二次型，然后直接读出反向后验 $q(x_{k-1}\mid x_k,x_0)=\mathcal N(\tilde\mu_k,\tilde\beta_kI)$。这也是「贝叶斯变换到高斯分布」这句话真正落地的地方：工具 ①负责翻方向，工具 ④ 负责把翻出来的东西认出来。
配套的一条：独立高斯的线性组合仍是高斯。$X\sim\mathcal N(\mu_1,\sigma_1^2)$、$Y\sim\mathcal N(\mu_2,\sigma_2^2)$ 独立，则 $$aX+bY\sim\mathcal N\!\big(a\mu_1+b\mu_2,\;a^2\sigma_1^2+b^2\sigma_2^2\big)$$ 用矩母函数三行就能证（DP §7 工具 ④ 有完整推导）。DDPM 的正向闭式解 $x_k=\sqrt{\bar\alpha_k}x_0+\sqrt{1-\bar\alpha_k}\epsilon$ 就是靠反复用这一条把 $T$ 步噪声合并成一步的。
