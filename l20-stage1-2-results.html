这是 Stage 1.2 计划的第一次实际运行：用 Stage 1.1 当天采集的 95 条 Quest→retarget→L20 示教，按计划的阶梯（B0／B1／M0／方案 A／方案 B）训练并在留出的 session 上比较，附影子手视频。结论先行：抬离前 1 s，学习模型比「保持当前姿态」好 3 cm、比最近示教和常数预测好 0.5 cm；残差形式的小模型在抬离时刻误差 0.9 cm；方案 B（Flow Matching）与确定性回归无差异且候选无多模态，方案 A（VQ-VAE＋AR）停在码本重建；一个只看当前 25 维状态的线性模型在 1 s 提前量上是最好的。数据侧的两个发现比模型更重要：抓取提示与方向提示都没有在标签里留下痕迹。

本页不是 Stage 1.2 的正式结果。计划要求的 240 条、144／48／48 按 session 划分不存在；所有 trial 都是 pinch，终点标签未经人工复核（每个 session 的 stage11_training_ready=False）。这里的数字是 PoC，用来决定协议和模型下一步怎么改。

三个只有录了才知道的事

  1. 抓取提示不是标签。pilot 的 pinch／tripod／power 提示全程都以 pinch 完成（操作者确认）；36／43 条抬离时只有拇指＋食指两点接触，三组终点关节的最近质心分类准确率 0.37 等于多数类比例。协议缺一个「实际抓型」字段；正式采集已改为 pinch-only。
  2. 方向提示不改变抓姿。正式 session 的 front／left／right／top 四组，抬离掌部位置均值差不到 1 cm、姿态一样、接近方位角都是 −150° ± 10°，标签离散度（1.1／2.7／1.1 cm）比 pilot 还小。坐着的人对桌上一个 cube 只有一种自然的捏法；方向多样性只能来自布局（cube 出生到身体另一侧）或仿真。

一句话。用生成式抓取模型（Dexonomy 在 L20 上做物理抓取合成 + DexLearn 条件归一化流）产的数据、不碰任何真人数据训练的预测器，在 95 条真人上失败：抬离前 1.0 / 0.5 / 0 s 掌心误差 12.1 / 10.9 / 9.0 cm（DexLearn）、12.6 / 10.6 / 10.2 cm（Dexonomy 直出），比「保持当前姿态」（4.56 / 3.48 / 0.97）还差。原因不在掌姿——生成数据的掌姿分布与真人一致——而在关节构型：真人抓取时的拇指与非任务手指姿态不在生成数据的支撑里，输入窗口里的 16 个关节指令通道把模型推出了训练分布。把关节通道去掉，掌姿部分能迁移（1 s 前比保持好 0.8–1.0 cm）；换成覆盖式模板，全输入回到 5.7 / 4.1 / 2.9 cm。但没有一个零真人的臂过验收线（≤ 3.15 / 2.31 / 1.51 cm），抬离时刻全部差于保持；与真人混合或预训练也没有增益。在线部署不变（仍是 v7 的混合模型）。

在线学习四问：没有一种新的在线学习超过 v11 的混合，瓶颈在数据而不在算法或基座

一句话。三个离线实验（协议同 v9／v11 的逐次先测后学）回答用户的四个问题：① 旧数据集只能答「同一个人、同一天、没看见预测时哪种在线学习学得快」，答不了跨人、跨天、人对预测的反应；新数据不是更多生成数据，而是真人在环的在线学习录像（今天 10:41 的 6 次抓取是第一份）和其他操作者。② 会自适应的操作者做成了闭环稳定性检验：仿真操作者向 1 s 前看到的影子手靠拢（增益 g ≤ 0.5），没有任何学习器发散，但现场日志会看到的误差（对实际落点）比对本来要抓的位置低一半（switch 留出段 1.35 → 0.67 cm），对 intent 的误差一点没降；「学会人的自适应」要多位操作者在环的数据，旧数据做不到。③ 更大的基座：同配方把 M0 从 4.6 万放到 148 万参数（各 3 种子）：零样本 1 s 宽 512 好 0.3–0.5 cm，但宽 32 也好于现用的宽 128（不单调，在种子离散 0.2–0.3 cm 内）；在线学习后留出段 1 s 三种宽度 1.57 / 1.48 / 1.45 cm（差 ≤ 0.12），formal 流上现用宽度最好；只有抬离时刻在线学习后宽 512 好 0.1–0.3 cm，代价是每次更新从 0.07 s 变成 1.37 s——容量不是杠杆（生成式 DDPM／FM 作基座 v1／v11 已否定）。④ 现在的在线学习不是「大学习率 + 新数据」：是小学习率（1e-4）、全缓冲重拟合、热启动、向基座回拉；用户描述的那种（只学最新抓取、大学习率）实测是会学的方法里最差的（留出段 1 s 2.64 cm 对微调 1.86、混合 1.36，过线从第 6 次推迟到第 12 次）；遗忘／滑窗、合成回放、kNN、贝叶斯末层、换远端的混合——没有一个超过 v11 的加权混合。现场部署不变。

问题与做法。用户（10-07 下午）把 Stage 1.2 分成两条线：生成式 session 管数据生成，本线管在线学习，问四个问题。三个实验都用 v9 的逐次模拟（rec = 95 条按录制顺序，1–43 调参、44–95 留出；formal = 52 条单独从基座开始）、v11 的调参目标（pilot 上三个时刻各除以验收线）、对 switch 与对 ft 的逐 trial 配对 bootstrap、过线次数；新加一个判据「新 session 回弹」= rec 流 6 个 session 边界上新 session 前 2 次减上一 session 末 3 次。没有动 v9–v12 的任何在线学习文件；M0 只加了可选的宽度参数（默认网络逐键不变，有测试）。口径：全部是离线逐次模拟或仿真的操作者；真人在环的在线学习只有今天一场 6 次抓取，不构成结论。

与已有的两个仿真人的区别：Stage 1.3 的人群 v2是物理辅助的闭环——机器人的手指按 α 自己合拢，仿真人在关节空间里有缺陷并对辅助作出反应（迟滞、让步、减力），被评的是 RL 残差策略的抓取成功率；Stage 1.4 的 H2Hist（1.3 结果 v5，即 Q6）是把会话历史编成策略的输入，没有增益。本节是纯显示条件（Stage 1.2 的影子手，没有物理辅助）：仿真人改变的是终点（向看到的预测靠拢），被评的是预测器自己在闭环里的收敛与偏差，不是策略的成功率；两边用同一个概念（conformance／αh），对象不同。每次抓取：当前模型在自然录像的 1 s 评测窗上的预测 = 操作者在抬离前 1 s 看到的影子手 ŷ；操作者的实际落点 y′ = y + g·(ŷ − y)（只动掌心位置；影子离 intent 超过 6 cm 时不跟）；最后 1 s 的掌心轨迹按 smoothstep 渐变到新落点，训练窗与评测窗都从扭曲后的轨迹重切；模型在扭曲后的评测窗上打分两次——对 intent（自然标签）和对 realised（实际落点）；然后学 (扭曲窗, y′)。增益 g = 0（= 实验 1）、0.25、0.5、以及「信任」规则（g = 0.5·clip(1 − 近 5 次影子手误差 / 4 cm)：影子越准人越跟）。臂：不学习／线性修正／微调／混合，两条流，随机方法 2 个种子。这是什么：在明确行为规则下的闭环稳定性检验；不是什么：任何真人的模型——没有一位操作者在看着影子手的条件下被系统录过（10-04 两条、今天六条），g 无法校准。

补记 · p(a | o) 直观图：这个人的抓取是生成分布里的低概率模式，还是另一个分布？

用户问基座能不能学到「抓取」这项技能本身、人用的不同的 a 是同一分布里的不同概率还是不同的分布、有没有可视化。做法（training/artifacts/stage12_intent/online/study_v14/diag_pa_given_o/）：对 95 条真人的每个评测窗，在基座的归一化掌姿通道上找生成数据（gd_free 的 cube054，612 条）里最近 1 秒运动最像的 50 个窗、和操作者自己其它 trial 里最像的 25 个窗，画它们的抬离掌位——两边的经验 p(a | o)。结果（95 条中位，1.0 / 0.5 / 0 s）：生成云的离散 7.0 / 5.5 / 2.6 cm，离真实落点最近的生成样本 5.8 / 6.6 / 5.6 cm，没有一个生成样本在 2 cm 内（只按末帧掌心位置匹配也是 3.2–3.6 cm、0 %）；操作者自己的云离散 1.9 / 1.8 / 1.5 cm、最近点 1.2 / 1.1 / 1.0 cm、40–52 % 在 2 cm 内；不加条件时整个生成终点集合离操作者终点最近 3.2 cm（37 % 在 2 cm 内）。基座 4.2 / 2.9 / 1.3 cm 好于生成云的局部均值 7.1 / 7.8 / 8.7（网络在插值，不是查表），留一 trial 的线性修正 1.7 / 1.5 / 1.4 逼近操作者云的离散。

怎么读。① 给定同样的运动，生成数据会去的地方离这个人真正去的地方 5–7 cm，所以不是同一分布里的低概率模式，是另一个条件分布：「什么运动通向什么终点」这张映射是这个人自己的；生成终点集合只粗略覆盖了落点区域（3.2 cm），差的是 p(o | a)——人怎么靠近，与 v10、v13 的结论一致。② 基座能学的「技能」是几何：对这个物体哪些掌位是物理上可行、稳定的抓取（生成库是物理复验过的）；学不到的是这个人从哪条路靠近、停在可行集的哪一点。③ 对建模的含义：单人内 p(a | o) 是单峰的（v1 的 FM 在这位操作者上 = M0 + 0.7 cm 抖动），跨人群的多模态在生成基座里存在（1 s 时离散 7 cm），但新人的模式不在基座的模式上，所以「保留基座的多模态、在线只学一个选择器」现在行不通，必须像微调／线性修正那样平移映射；要让选模式成立，生成分布得先把人包进去（操作者风格挂点 + realism 检查），那时再比 FM 基座 + 选择器 与 M0 + 平移。
