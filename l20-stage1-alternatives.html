Stage 1.2 其他方案：数学推断与 VLM 辅助

同一批 Quest 3 示教，比较“学习运动规律”“用数学推断目标”和“用 VLM 提供抓取先验”。共同问题是：能否在动作完成前，预测用户最终确认的 L20 抓姿？

状态：四个其他方案均待实现、待评估；本页只制定并行对照协议，没有训练结果。Stage 1.1负责冻结数据，Stage 1.2 主方案比较确定性回归与 Flow Matching；本页说明可替换的 Human Model 和比较方法。

可以并行测试，也仍需采集验证数据。数学方案可先手工设定模型，VLM 方案可先用预训练模型，都不要求从零训练大网络；但它们是否理解了这个用户，必须用用户确认的终点检验。LSTM 用于 Bioimpedance 信号处理，不是此处 Human Model 的既定结构。

当前优先做 B0、M1、M2；S1 与 H1 可并行准备。固定 cube 的功能语义很少，同一物体也对应多个用户抓姿。VLM 在这里可能没有增益；保留 S1 作为诊断对照，恰好能检验“物体理解”与“用户意图理解”的差别。是否扩展到带把手等物体，应另开后续实验，不改变本轮 cube 范围。

共同输入输出：比较完整抓姿，避免只比抓取区域

统一终点、统一候选、统一回放时刻。主指标始终针对物体坐标系中的 L20 掌部位姿＋16 个主动关节。VLM 的区域或文字不能直接与连续回归的姿态误差比较，必须先落到完整抓姿。
X_t = history(T_OH, hand_shape, tracking_validity), observations available by t
g_T = (T_OP,T, q_T) : user-confirmed final L20 grasp pose
C = {g_1, …, g_K} : fixed candidate bank from training demonstrations
Predictor → target_palm_pose + target_q + timestamp + validity
optional: candidate_ids + belief/scores + uncertainty_status

沿用主协议的坐标、手形特征与终点定义。M1／M2 可使用同一 retarget 将历史人手掌映射到 L20 参考掌姿；这仍是用户参考，不用接触后仿真实际关节替代用户动作。新增速度、方向和手形变化只从历史因果计算。

已有数据与本轮待补字段分开；不把当前采集原型当作已验收数据集
共同部分本轮约定对比较的作用
运动与终点Quest 原始手／头姿、有效性、时间戳、retarget 参考与仿真实际状态分存；最终抓姿需用户确认。所有方法在同一预测时刻接受当时已经可获得的数据；终点只作标签。
候选库 C先只取训练示教的已确认完整终点，保留连续掌姿／关节、来源与版本，不只留“两指／三指”类别。M1、M2、S1、H1 用同一 C；不得加入测试示教终点。B0 仍保留连续输出。
场景语义输入S1／H1 起步用试次开始时的物体场景渲染与带 ID 的候选说明，屏蔽示教提示、真值标签、未来影子手及真实终点。无需先开通真实相机采集；渲染数据是额外待生成产物，不能把事后终点图交给 VLM。
场景几何同一 cube 几何、物体坐标和 L20 模型；全部条件可用。渲染视角、候选 ID 到物体区域映射固定。隔离语义推断差别；若增加深度、手部图像或语言指令，单列输入增强实验。
标签与时序缺口V1 已有 host 记录资产；截至 2026-09-12，V2 为 Quest 物理＋Mac retarget，正式 session writer、确认／取消／改意图等仍待接入。仿真终点来自实际物理运行端；不同管线分开标版本。控制后的状态不能反作同周期控制前的观测。

候选库是可行的起步近似，不代表抓姿只有有限几种。先报告它是否覆盖测试终点：仅在离线分析中，计算“知道真值后从 C 选最佳候选”的 oracle 覆盖率与误差。oracle 不是可运行预测器；库外目标要单列。如果库的表达上限已经很低，先扩展训练候选，不能把全部误差归因于意图推断。

第一版不做几何修正，直接比较原始预测和几何异常。若后续增加局部优化，所有方法使用同一修正器与预算，分别报告修正前后误差与失败比例；不能只有 VLM 获得额外姿态优化。

其他方案 M1：几何一致性评分

假设：用户正在朝最终抓姿靠近；当前的运动方向、掌部朝向与手形，可以帮助给候选终点排序。这是最容易解释的数学基线，状态：待实现。
  1. 准备候选。复用训练示教终点 C，确认坐标、限位与候选来源；不额外收集一套重复数据。
  2. 计算历史特征。在相同窗口中计算掌位置差、SO(3) 旋转角差、手形差与接近方向一致性。低速或已到候选掌位置时方向无定义，省略方向项；追踪无效不补成新证据。
  3. 选择目标。用训练数据估计各特征尺度，在验证集选择权重；按加权代价取最佳完整候选，保留 top-k 诊断，不平均不同手形。
  4. 做影子手对照。对比“当前姿态保持”和“只按掌部距离选候选”，检查方向／手形特征是否带来提前量，而不只是到终点后才匹配。
输入输出、数学形式与失败判据
E_k(t) = w_p d_p² + w_R d_R² + w_q d_q² + w_v (1 − cos(angle(v_t, p_k − p_t)))
k* = argmin_k E_k(t), predicted grasp = g_k*

各距离先按训练数据确定的尺度归一化，位置用米、旋转用弧度，关节按统一单位和顺序。窗口聚合也须固定为因果处理；权重与窗口长度是待选择参数，没有预填最优值。位置或方向并不能独自确定最终手形。

输入：历史 retarget 掌姿／关节参考、cube 几何、C。输出：最佳完整候选及代价。代价间隔只是排序证据，不是置信概率。交付：特征定义、参数来源、逐示教预测与误差图。失败判据：总选离当前手最近的姿态，提前量不优于距离对照；或在候选边界频繁跳变。相近前缀对应不同终点时，应保留不确定，不能声称仅靠数学消除了歧义。

其他方案 M2：递归贝叶斯 Human Model

假设：用户最近的新动作更符合某个目标；累积行为证据，比每帧独立打分更能稳定预测。状态：待实现。参考 Jain 与 Argall 的递归贝叶斯目标推断，此处为面向 L20 抓姿的拟议适配。
  1. 建立目标 belief。仍使用 C，先用均匀先验；目标转移允许从 A 改到 B，不把旧目标永久锁住。
  2. 定义行为似然。对每个目标假设一个局部趋近运动：预计掌部平移、旋转和关节参考如何变化。以实际新动作与预计动作的残差构造联合似然；训练／校准数据决定尺度与噪声。
  3. 递归更新。每次用新证据更新并归一化 belief，输出最可能完整抓姿；追踪失效跳过观测更新，明确取消使目标失效。
  4. 检查稳定性与改变。主测试仍用固定意图示教；额外用已标注改意图片段测切换延迟、旧目标持续时长和错误切换。
输入输出、数学形式与失败判据
b_t(k) ∝ L(Δz_t | g_k, z_previous) × Σ_j A_jk b_previous(j)
Σ_k b_t(k) = 1, predicted grasp = g_argmax(b_t)

z 为同一坐标约定下的掌姿／关节参考；Δz_t 是新的有效运动增量，旋转增量在 SO(3) 上计算。A_jk 是目标转移概率；L 是给定目标时观察到这个动作的似然。局部趋近模型可以手工定义，之后只用训练／校准示教估计参数；不是假定所有人的运动都严格最优。

避免虚假的自信：不要把高度重叠的整段窗口每帧当作独立新证据反复相乘，也不要将来自同一追踪信号的距离、速度、手形无条件视为独立。需采用一致的采样间隔／联合残差模型，并在验证数据检查过度集中。

输入：与 M1 相同的行为信息＋上一步 belief。输出：完整候选、候选分布及有效性。交付：似然／转移定义、belief 时间曲线与切换案例。失败判据：比 M1 更迟才改正错误，或在目标不在库内时仍很自信。belief 是“给定模型及候选库”的概率，不天然等于预测准确率；置信度须按共同协议校准。

其他方案 S1：VLM 提供物体与抓法先验

假设：物体形状与场景能提示哪些抓法合理。VLM 先负责理解与排序，完整姿态由统一候选库提供。状态：待接入预训练模型、待准备渲染输入；这是语义先验对照，尚不是完整的用户行为模型。
  1. 准备可追溯输入。试次起点渲染 cube 与环境，用固定 ID 表示候选抓取面／区域及完整抓姿的说明。相机、场景状态、候选展示方式固定，输入不包含最后抓姿。
  2. 限制输出。让 VLM 返回候选 ID 的排序或分数、涉及区域及简短理由，允许“证据不足”。只接受 C 中存在的 ID，记录模型版本、prompt、请求和响应。
  3. 落到完整目标。通过 ID 查表得到掌姿＋16 关节；不把文字“抓左侧”当成已求出抓点、接触力或电机控制。
  4. 测试它是否辨别人。同一 cube 上用不同用户终点测试。若始终推荐同一种合理抓法，但与用户选择不一致，记录为语义先验的能力边界。
输入输出、文献关系与失败判据

输入：物体场景图像、候选几何／区域说明。首轮只用通用“抓取 cube”任务描述，不将采集时给人的“两指／三指”提示透露给模型；若加入明确语言意图，应单列为用户额外提供信息的条件。输出：候选排序和映射后的完整抓姿。

ShapeGrasp借助几何分解和 LLM 推断适合任务的部位；ThinkGrasp利用视觉与语言理解目标、部位及遮挡。这些提供模块分工的依据，不证明“看一张物体图就知道用户准备怎么抓”，也不提供已经适配好的 L20 Human Model。

训练与标注：可先不微调，但仍需配对示教做测试，少量验证样本用于固定 prompt 和排序映射。VLM 自报“90%”不直接用作概率。交付：可复现的输入图、候选表、prompt／模型版本、解析失败记录和输出。失败判据：没有意图区分能力、输出非法 ID，或收益不足以抵偿等待时间。物体图不变时只计算一次；这一路不应伪装成每帧有新的人类证据。

可留作下一轮的变体：加入截至 t 的手部图像／短视频，让 VLM 看动作。此时它获得了新的行为输入，须与“数值轨迹＋相同可见信息”的条件单独比较，并记录遮挡、渲染与 token 成本；不把这个变体的成绩混入物体语义先验实验。

其他方案 H1：VLM 先验＋贝叶斯行为修正

假设：场景先验帮助动作早期缩小候选，用户行为随后纠正它。状态：待 M2／S1 最小接口后组合；这是优先考虑的 VLM 辅助 Human Model 方式，效果待比较。
  1. 初始化先验。将 VLM 排序按固定规则转成分布，与均匀分布混合，给所有候选保留非零可能性。排序映射和先验强度只在验证集选择。
  2. 用行为更新。后续完全复用 M2 的似然、目标转移和采样时序；静态图像的同一先验只注入一次，不能每帧重复增强。
  3. 处理冲突。如果用户持续朝先验不偏好的抓姿运动，允许 belief 转向；场景改变再触发新语义推断。几何无解只标记不可行，不伪称用户换了意图。
  4. 做消融。与均匀先验的 M2、仅语义的 S1 对照；另设错误／打乱先验诊断，检验系统能否被真实行为纠正。
输入输出、融合公式与失败判据
b_0(k) = (1 − λ) / K + λ π_VLM(k), 0 ≤ λ < 1
after initialization: use the same recursive update as M2

π_VLM 是按记录规则归一化的候选分布，不是 VLM 已校准的真实意图概率；λ 控制先验影响。λ=0 应退化为 M2。主实验冻结模型与参数；不能在看到测试结果后调先验强度。

输入：M2 行为输入＋S1 场景先验。输出：同 M2。交付：逐时刻 belief、先验覆盖／误导案例、各消融的误差和延迟。失败判据：只让默认抓法更稳定、压低少见意图的覆盖；或先验错误后比 M2 更难恢复。

VLM 超时、非法响应或场景版本过期时，记录回退并使用 M2；不等待它才继续数值推断。按请求时刻与结果真正到达时刻回放，不能把后来得到的语义结果提前塞进预测。未来若场景更新时重新初始化，需明确 reset 规则并单独测量，不能重复累乘同一画面的先验。

怎样比较：先判断意图预测，不混入抓稳能力

同一测试示教、同一历史截止时刻、同一终点真值。结果要同时回答“准不准”“早不早”“是否保留不同抓法”和“是否值得等待”。全部先用影子手，不修改用户指令。
  1. 冻结数据划分。按完整示教划分训练／验证／测试，另留独立 session；同一示教的相邻窗口不能跨集合。候选库、归一化只由训练数据生成，校准与选型用验证数据，测试集不改模型。
  2. 对齐因果输入。动作百分比／最终时长只作事后分组。排除确认后的窗口作为“提前预测”证据；另外报告首次接触前的结果。改意图前窗口不倒贴新终点，失效追踪与取消单列。
  3. 跑共同对照。当前姿态保持、仅距离候选、训练片段检索、B0、M1、M2、S1、H1；候选 oracle 单列为诊断。检索只用当前历史匹配训练片段，不用测试最终时长对齐。
  4. 统一计分。容差、持续正确的时间要求和拒绝规则在验证集确定，测试前冻结；按示教汇总配对差异及不确定区间，不把每帧当独立样本。试跑小样本只用于排错，不得声称统计优势。
待执行指标与解释；不预填实验成绩或最优阈值
指标统一定义避免的误判
终点姿态误差掌平移距离、SO(3) 旋转角、16 关节 MAE；辅以 FK 指尖误差。按预测时刻或离线动作进度分组。部位判断正确不等于完整抓姿正确；旋转不用欧拉角 MSE。
提前量与持续正确首次进入全部约定容差且满足预定保持要求，到用户确认终点的时间；报告未达到的示教比例。不能只算成功预测样本，也不能把临时掠过容差算早预测。
意图覆盖与候选上限各采集手形／接近方向分别报姿态误差与成功覆盖；附 C 的 oracle 容差覆盖及库外样本表现。总是猜常见抓法的模型可能总体误差小；库的限制与预测器错误分开。
不确定与改意图有校准概率时检查可靠性／Brier 分数；所有方法报不同拒绝覆盖率下的误差。有事件标注时另报切换延迟和误切换。定义事件为“完整预测在约定容差内”，不是随意把候选最大分数当成功概率。
时延与资源共同设备上记录数值推断耗时；VLM 记录渲染／编码、网络、模型响应、解析总时间与 p50／p95、调用次数、实际费用及回退比例。缓存与未缓存分开；提前量必须按预测实际可用时间计算。
几何异常同一模型检查限位、耦合、穿透；输出失效、非法候选与无解均计入分母。本轮不验证承重、摩擦稳定、抗扰、释放或 pick；几何可行不能当抓稳。
在线学习怎样作为后续对照，不污染第一轮比较？

先比较冻结版本；每帧更新 belief 属于 online inference。之后可单列个性化实验：每次用户明确确认一个试次后，才用该次标签更新偏好、似然参数或小模型，并从下一试次开始评分。保留相同按时间排列的示教流和冻结模型对照，禁止用本次最终确认改善本次早期预测成绩。

记录更新前后参数、可用标签数量与每次耗时，不用模型自己的预测当用户确认。是否更少改错、是否对新意图产生偏见，与总体误差一起报告。在线学习不是当前采集验收的前提。

当前四步：共享采集，再逐条接入

  1. 完成共享数据小试跑。沿用主方案的 10 条调试示教计划，补齐确认标签与因果回放；检查能否生成仅含当时场景的 VLM 输入。10 条用于检查流程，不预设足够训练或比较。
  2. 冻结一版数据契约与 C。写明划分、候选来源、坐标、输入时间界线，先复现当前保持、检索与 M1；B0 数据训练准备同时推进。
  3. 接入其他方案。数学路线实现 M2；语义路线准备 S1 图像／输出解析，再合成 H1。各路线复用同一录制，避免重新采四套数据。
  4. 交付比较记录。另建带 run ID 的结果页，回链本协议；附每条路线状态、实际数据量、误差／提前量图、影子手回放及失败案例。证据不足保留待评估，不填名次。

选择依据：若 M1／M2 已满足提前量与意图区分，优先保留更简单路线；若 B0 在同一标注预算下更好，扩展其数据；若 H1 仅对少数情况有用，记录作用条件。VLM 没有收益也应保留结果，作为当前 cube 场景的边界，而不宣称其在所有物体上无效。

方法依据与复用边界

下列文献提供模块设计依据；M1 的评分与 H1 的混合接口是本项目候选设计，尚未验证，不是论文原算法复现。更多感知理解文献见文献阅读库的“感知与理解”分类。

  • Recursive Bayesian Human Intent Recognition in Shared-Control Robotics — Siddarth Jain、Brenna Argall，IROS 2018。作者论文。输入候选目标与非语言行为观测，输出目标 belief；有用户研究。复用数学结构，L20 连续抓姿候选、似然与校准需另做；本次未核验可直接复用的代码或数据。
  • ShapeGrasp: Zero-Shot Task-Oriented Grasping with Large Language Models through Geometric Decomposition — Samuel Li 等，IROS 2024。论文 · 作者项目与资源入口。几何分解、对象名称与给定任务 → 部位语义与抓取部位；不同于观察用户后推断目标。代码／数据入口由作者提供，本页未复现，外部 LLM 与 L20 姿态接口仍需适配。
  • ThinkGrasp: A Vision-Language System for Strategic Part Grasping in Clutter — Yaoyao Qian 等，CoRL 2024。论文 · 作者项目与代码入口。视觉与语言目标 → 目标／部位理解并衔接抓姿生成；本轮只借鉴感知与几何执行分工，不引入清障长程任务。代码入口可查，本次未核验完整依赖／权重可运行性，不当作即用 L20 模型。
