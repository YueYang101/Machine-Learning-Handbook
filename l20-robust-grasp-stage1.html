§ 1长线不变，第一步只问一个问题

长期目标：跨物体、跨任务的稳定抓取共享控制，能够根据人的意图和抓取风险动态调整辅助，同时保留人对目标、运动与释放的控制。Stage 1.1：在同样外部腕部运动、初始抓姿和执行器限制下，在线手指调整是否比固定闭合更能减少滑移与掉落？

总路线页负责阶段关系与长期研究候选；本页负责第一轮实验的具体步骤。共享控制页保留系统架构及人机接口背景。三页不互相替代。

§ 2不是不抓起来，而是先不学习“怎么抓起来”

固定流程负责闭合与抬起；学习控制器负责后面的 8 秒。两个控制器比较时，必须从相同且能真实承重的初态开始，而不是各自挑最有利的一次抓取。
  1. 准备候选。按 §3 得到一个 L20 包握 reference。使用现有 CubePick 资产中的方块：边长 0.07 m、质量 0.108 kg；不同时换场景和任务。
  2. 建立抓取。用固定的闭合／抬起流程，或用现有策略离线获得候选。动作要经过真实模拟动力学，不能把穿透的关节姿态直接当稳定抓姿。
  3. 解除所有支撑。物体底部至少离桌面 0.10 m；物体没有 weld、悬挂或其他隐形支撑。若只能在初始化时临时固定物体，必须先解除，再开始下面的检查。
  4. 稳定检查 0.5 s。使用固定 PD，不计训练奖励；没有桌面／地面接触、无明显穿透、无持续滑移。建议窗口内相对平移漂移 ≤2 mm、相对旋转 ≤2°，末端相对速度 ≤0.01 m/s。阈值先审计数值噪声，合格后冻结。
  5. 记录初态。保存模型及参数 hash、完整积分状态、控制目标、初始化来源、reference 和重建说明；同一 backend 支持精确恢复。换 backend / 物理参数后必须重新稳定，不能假设原快照仍处于平衡。
  6. 开始计分。以稳定检查结束时的手—物体关系为固定目标，清空 episode 指标，运行 8 s = 200 个 25 Hz control steps。运动／外力只在计分开始后出现。

初始化失败单独记账。每组最多尝试 20 次；仍失败记为 initialization failure，不无限重采样。条件持物指标的分母是合格初态数，同时单列候选总数、初始化通过率与失败原因。比较 controller 时共用同一批初态；不能按每个 controller 的表现重新筛选。

两个入口。主入口是“已抓住状态 → 抗扰”，用于训练与归因；完整入口是“固定 pregrasp → 固定闭合／抬起 → 抗扰”，在本轮末期补验证。分别报告初始化、条件持物、完整流程成功率。桌面入口失败不会被从完整流程分母删除，也不等于一定是持物策略失败。

先用 1 个合格初态做 smoke，再用同一抓取类型的 3–5 个物理合格变体做 pilot。保存未见初态变体作验证／测试；不靠复制同一个快照制造“抓姿泛化”。

§ 3“像人”保留在哪里？

先保留抓取类型、拇指对向关系和功能接触位置，不要求每一帧都匹配人类关节角。人类先验负责提出合理 reference，物理检查负责证明它可以承重。

第一轮只选一个适合方块的包握类型。可以用现有 Quest／retargeting 流程记录少量参考，或在 L20 上标注类型模板；没有必要先接入大型人类数据库。retarget 必须服从 L20 的 16 个主动关节和 5 组耦合，不能把人手 21 维角度逐项复制。

  1. 检查掌面朝向、拇指对向以及哪些指节应接触物体；标出禁止靠关节极限／穿透形成的抓姿。
  2. 转为 L20 reference 后，调整物体相对位姿和手指闭合量，完成 §2 的物理检查。
  3. 冻结 reference；允许 residual 在有界邻域内调整。每次失败回放检查是否变成非预期抓取类型。
  4. 先记录自然度／类型保持，不立即加大权重的模仿 reward；若策略持续改变类型，先检查 reference 和动作边界，再做单独约束消融。

Dexonomy（RSS 2025）从每手型／每抓取类型一个人工模板出发合成抓姿，适合参考这一步；官方实现采用 MuJoCo，当前支持列表不含 L20，接入仍需手模型、接触标注与模板适配。CGF（RA-L 2023）是人类轨迹 retarget 后学习自然抓取动作的参考，适合以后做完整 approach / closure style；它不是本轮抗扰控制器的替代品。

对照公平性：固定 PD 和学习策略共用相同 reference。如果以后比较“有人类先验 vs 无先验”，必须把它作为独立消融，不能同时改变初态质量、controller 和动作范围。

§ 4控制接口与物理：先固定这些，再调 reward

Policy 只有 16 维手指输出；腕部由独立轨迹驱动。Residual 是相对 reference 的有界偏移，不是逐步累加直到关节极限。
$$q_{\mathrm{raw},t}=q_{\mathrm{ref}}+0.15\,a_t,\qquad a_t\in[-1,1]^{16}$$

0.15 的单位是 rad，是首轮建议，不是已测最佳幅度；所有 baseline 使用同一个允许目标集合。reference 按主动关节顺序存储，用关节名映射，不依赖 XML 隐含顺序。

$$q_{\mathrm{cmd},t}=\operatorname{clip}_{[q_{\min},q_{\max}]}\!\left[q_{\mathrm{cmd},t-1}+\operatorname{clip}_{[-v_{\max}\Delta t,v_{\max}\Delta t]}(q_{\mathrm{raw},t}-q_{\mathrm{cmd},t-1})\right],\quad v_{\max}=0.8\ \mathrm{rad/s}$$

关节范围与目标速率限制始终生效；记录 raw action、限幅后 command 和实际 q，避免把“输出很平滑”误当作“执行很平滑”。腕部 command 不经过 policy 修改。

§ 6干扰不是随便摇：先分开测，再混合

腕部运动模拟人怎么搬动物体；对物体施加外力模拟碰撞、阻力和负载。两类先分开，才能知道失败来自运动还是外接触。每次测试恢复初态，扰动的单位、坐标系、时间和实际实现值都记录。

6.1 Wrist trajectory bank

平移用世界坐标轴，旋转用 episode 初始 palm 的局部轴。使用起止速度、加速度为零的 minimum-jerk 段；在两个端点间往返并有随机停顿，不按轴顺序固定循环。

$$s(u)=10u^3-15u^4+6u^5,\qquad u=\operatorname{clip}(t/T,0,1),\qquad p(t)=p_0+A\,s(u)\,d$$

d 是单位方向；A 为位移，T 为单段时长。旋转用同一 s(u) 沿固定轴插值角度。检查真实加速度而非只看“移动了多远”：平移峰值速度为 1.875A/T，峰值加速度约为 5.774A/T²。

首轮训练候选：平移 A=0.02–0.10 m；旋转 10–30°；单段 T=0.8–1.6 s；段间停顿 0.2–0.6 s。限制平移加速度 ≤1 m/s²、角加速度 ≤5 rad/s²；超限轨迹重采样。先单轴，后混合；合成后再检查界限，不把每轴合格误认为合成运动合格。

6.2 External wrench bank

腕部静止，对物体施加六向力 ±x/±y/±z 和六向力矩 ±roll/±pitch/±yaw。坐标轴固定为 episode 初始 palm frame，并变换到仿真施力所需坐标。力作用于 COM；纯力矩单独施加。以后才加入离心接触点，因为偏心力同时产生力矩。

  • 脉冲：1–5 s 内随机开始，持续 0.24–0.48 s；上升／下降各 0.04 s，按 physics substep 平滑施加，不用理想瞬时冲量。
  • 强度：训练力幅值取 0.1–0.5 mg；力矩取 0.05–0.25 mgr，r=0.035 m 为固定报告尺度，不是解析抗扭能力。
  • 量纲核对：nominal m=0.108 kg、g=9.81 m/s² 时，0.5mg=0.52974 N；0.25mgr=0.00927045 N·m。质量改变后按当前质量换算，并同时报告归一化强度和实际 N / N·m。
  • 阈值扫描：另做单方向逐渐加力／加力矩，记录首次超限滑移强度；每个方向重置。到测试上限仍不失稳，报告“≥上限”，不假称测到了极限。

6.3 Physics randomization

在静态 nominal 通过后，逐步加入质量 nominal ×[0.8,1.2]，有效滑动摩擦 μ∈[0.3,0.8]。质量变更必须同步合理惯量，COM 第一轮固定。摩擦必须检查实际接触参数：不能只改 object geom，而手／物体的接触混合规则使生效摩擦仍是旧值。记录接触 pair 的实际 μ。

不同物理参数必须重新建立／稳定初态，并报告通过率；否则“只保留能初始化的低摩擦样本”会暗中改变任务分布。暂不同时随机 actuator gains、延迟、COM、对象形状和传感噪声。

§ 7Reward 1.1：具体算什么，为什么这样算？

主信号是“物体相对手掌没有滑走”，不是让物体停在世界某个点。移动手腕时，物体跟手一起运动应得高分；掉落、支撑作弊和失稳不能靠此前的累计 reward 算成功。

7.1 先定义测量量

$$T_{PO}(t)=T_{WP}(t)^{-1}T_{WO}(t),\qquad T^*_{PO}=T_{PO}(0)$$

W 是世界，P 是固定 palm site，O 是物体刚体坐标系；0 是通过稳定检查后的计分起点。目标关系在本 episode 内冻结，不能每步重设目标把累积滑移抹掉。

$$e_p=\|p_{PO}-p^*_{PO}\|,\qquad e_R=2\arccos\!\left(\operatorname{clip}(|\langle q_{PO},q^*_{PO}\rangle|,0,1)\right)$$

四元数必须归一化；绝对内积使 q 与 −q 等价。eR 使用 rad。方块仍按物体刚体坐标系记录旋转，90° 翻面不能因几何对称被当作“完全没滑”。

$$v_{\mathrm{slip}}=\|v_O-v_P-\omega_P\times(p_O-p_P)\|$$

所有速度和位置先统一到世界坐标，vO 是物体 COM 速度，vP 是 palm site 线速度。减掉叉乘项，才能使物体随手掌刚性旋转时得到零相对滑移；直接相减两个线速度会错误惩罚正常旋转。

7.2 每步奖励与一次性事件奖励

定义位置核 Kp=exp[−(ep/0.01 m)²]，旋转核 KR=exp[−(eR/10°)²]。以下每个 C 都归一化到 [0,1]；Δt=0.04 s。H=1 表示仍在计分阶段，非计分初始化不调用本 reward。

$$r_t=\Delta t\,[H+2K_p+K_R-0.20C_v-0.05C_{\mathrm{ref}}-0.02C_{\mathrm{slew}}-0.10C_{\mathrm{effort}}-0.50C_{\mathrm{sat}}]-5I_{\mathrm{fail}}+2I_{\mathrm{complete}}$$

括号内是每秒收益／成本，乘 Δt 后不同控制频率的物理时间可比较；失败 −5 和合格完成 +2 只在事件发生时记一次，不乘 Δt，不在终止后继续累积。fail 优先于 complete。

所有权重都是待 pilot 核验的建议起点，不是论文原始 reward

量级自检：误差和成本均为零的理论单步上界是 0.04×4=0.16；8 s 持续上界为 32，加一次完成奖励为 34。位置误差 1 cm 时 Kp=e⁻¹≈0.368。这里是公式算例，不是实验数据，也不意味着真实承重可以零 effort。

这轮不加：reach、物体世界目标点 bonus、反复 lift bonus、每多一个接触点奖励、完整人类姿态模仿或强 minimum-force 目标。它们会与当前问题混淆。完整桌面入口的前置阶段单独计分，不偷偷把 CubePick 的 near / very-near 收益叠进来。

调参纪律：先记录每项原始值、加权值与 episode 积分，看是否某项占满；每次只改一类权重或阈值，记录版本与理由。不能看到测试集失利就改测试阈值。若所有简单策略也失败，先检查初态／物理／控制权限，而不是立刻加 reward。

§ 8成败判据与恢复：不要只看 reward

“没掉”“没有明显滑移”“受扰后恢复”是不同成绩。第一版分别报告；一个短暂滑移后恢复的 episode 可以算持物完成，但不能算全程严格稳定。
数值阈值均为 pilot 候选，固定后再生成测试集
事件／指标定义处理
Drop / support contact计分阶段物体触桌面／地面；或物体与手失去有效接触持续 ≥0.12 s终止失败；有效接触按总法向力 >0.05 N 初筛，先验证阈值高于数值噪声
Hard slipep>4 cm 或 eR>45°，连续 ≥0.12 s终止失败；在 physics substep 累计持续时间
Wrist tracking failure期望／实际腕位误差 >2 cm 或 >10°，持续 ≥0.20 s单列失败，保留在全流程分母；无物体时也失败则轨迹／servo pre-gate 不通过
Numerical invalidNaN/Inf、solver 异常或明显穿透／能量爆炸记录 invalid trial 与状态，停止排查；不算作“抓取不够聪明”，也不丢掉分母
持物完成满 8 s 无失败，末 0.5 s 持续 ep≤1 cm、eR≤10°一次完成奖励；episode 成功，不用成功步数占比代替
严格稳定持物完成，且全过程 ep≤2 cm、eR≤20°独立 strict-stability 指标；初始段也计入
恢复时间扰动结束到首次重新进入 ep≤1 cm、eR≤10°，并持续 0.5 s未恢复记为 censored / failure，不能只平均恢复成功的 trials

contact dropout 和 hard-slip debounce 是不同计时器；step 内触桌／掉落不应因 step 末刚好恢复被漏掉。本版本定义为 8 s 有限时域任务：物理失败和到达任务终点都结束 episode，均不 bootstrap 到 reset 后的状态；是否成功由上述判据另行决定，正常结束不记失败罚分。仅因训练器外部中断而发生的真正 truncation 才另行保留 bootstrap。critic 可见剩余时间，actor 不接扰动时间表。完成 bonus 只记一次，reset 清空历史。

同步保存 peak / P95 actuator effort、饱和时长、相对滑移峰值与积分、实际腕部轨迹、initialization acceptance。没有经过触觉标定，不报告“易碎物体安全”或真实材料受力上限。

§ 10训练顺序与预算：每一段都能停止

先验证环境，再做小预算曲线；不要直接跑满 100M steps。以下是候选训练设置，不是已实现的 config，也不要求先连接真人。
  1. T0 无学习验收。固定物理参数，跑 B0/B1 静态及小扰动；先取得可复现的初态和 baseline 视频。
  2. T1 Smoke。单个 nominal 初态，静止／低幅运动，约 1M environment steps，seed 0。只验证 reward 有限、action 权限正确、终止和日志正确，不宣称泛化。
  3. T2 Nominal pilot。3–5 个同类型初态，加入完整训练腕部轨迹和独立 wrench 场景；B2 的预算上限先设 10M steps。
  4. T3 DR pilot。B3 使用相同训练轨迹、网络和预算；质量／摩擦先窄后宽。训练场景分配：20% 静态、30% wrist-only、30% wrench-only、20% 混合。预热进度按训练 steps 固定，所有学习对照一致，不看 test 调课程。
  5. T4 配对验证。约每 1M steps 在固定验证集评估；按照持物完成率优先、再看严格稳定率和 effort 选 checkpoint，不按最高训练 reward 选。
  6. T5 三 seed。seed 0 通过环境与 nominal gate 后，复跑 seeds 1、2；若 10M 仍在明确改善，可按预先约定延长到 20M/seed，否则先诊断。超过此预算重新立版本决策，不自动无限加算力。

§ 11测试集、过拟合与真正的第一张表

现在就隔离测试，不现在就要求跨一切。先证明同一个物体在未见轨迹／扰动组合上有效；单物体结果不能写成“跨物体通用”。

验证集建议 96 episodes；最终 test 192 episodes，分为以下 6 组、每组 32 条。训练随机数 seed 范围 0–99,999，验证 200,000–299,999，测试 300,000–399,999；这仅用于避免随机流重用，不能替代初态来源、轨迹类型和物理参数组合的实质隔离。

每个 controller 共用冻结的 scenario manifest，test 不参与调参
组测试内容泛化声明
E0Nominal 静态保持，初态变体基础 sanity
E1ID 范围内未见 wrist 轨迹参数／组合同分布未见轨迹
E2ID 范围内未见 force / torque pulse同分布未见扰动
E3ID 范围内未见 wrist + wrench + 物理参数组合组合泛化
E4训练单轴之外的斜向／多轴轨迹，仍满足相同加速度界限轨迹结构 OOD；训练 bank 中明确不包含该保留子类
E5力 0.5–1.0 mg 或力矩 0.25–0.5 mgr，其余受控强度 OOD，只测承受范围，不保证必须成功

每条 manifest 必须保存初态来源/hash、物理参数、轨迹或生成器版本、所有扰动时刻及幅值、数值设置。对 train 与 test 做实际参数／轨迹重复检查；反复查看 test 视频并据此调模型也算 test 泄漏。

结果表的列：initialization acceptance、条件持物完成率、strict stability、失稳／掉落／腕部失败／数值异常数量、ep/eR peak 与 P95、恢复率／恢复时间、effort P95、饱和比例。报告每个 seed 和每个组，不只合并平均；小 pilot 不包装成大规模统计证明。

配对重采样同一 scenario ID 比较 B3−B0/B1，报告 95% bootstrap CI；有多 training seeds 时以训练 seed 和 scenario 分层，并保留每 seed 原始值。3 seeds、每组 32 条只能用于方向判断，最终论文规模在下一版确定。掉落 episode 不因无法计算后续滑移而从成功率分母删除；只对成功者计算的滑移统计要明确标注条件。

扩展顺序：Stage 1.1 内看未见运动；Stage 1.2 加圆柱／偏心物体与完整抓取入口；以后再做 held-out object instance / category、未见操作者和未见任务。公开数据库要先按人／物／序列切分，再 retarget，不在 retarget 后随机打散。
