A1 · S01 的具体操作：先做一条，再做一批

  1. 加载同一个对象。只用现有 70 mm / 108 g cube。登记 mesh 与 collision hash，不切换为旧 ORCA 的 cube / bottle。参考点采用固定 palm site，坐标与单位按候选合同。
  2. 取得原始包握输入。保存右手静态关键点和接近闭合的一段原始序列；若没有可用采集，人工在 L20 模型上标注包握并记录该来源。检查拇指与至少两个非拇指构成对向包握，掌面朝向与接触区域符合目标类型；这只是类型筛查，仍须承重验证。
  3. 运行既有映射。先用本地 vector，保存 16 主动关节目标与全部耦合后的 FK；angle 输出只作对照。小指限位／curl 不手工删除记录，按 retargeting 缺陷页定位。若用 DexPilot，保存其实际门控阈值、scale、点对和库 commit，不能只把 vector 改个名字。
  4. 构造三个不同语义的目标。q_pre 是不与 cube 穿透的预闭合目标，q_grasp 是几何接触目标，q_hold 是固定控制器实际承重目标。沿标注 flexion 方向，以 0 / 0.05 / 0.10 / 0.15 rad 为开发集闭合候选，经限位、0.8 rad/s 速率约束与物理回放选定；这一初始化标定与后续 B1 固定偏移搜索分开留档。
  5. 保留来源。source ID、retargeter、人工修改、优化 refinement、q_hold 选择依据全部存入 candidate。初态通过后令 controller 的 q_ref=q_hold；q_ref 在计分期间不因物体滑移而更新。

公共数据 adapter 的执行入口：先从 ContactPose 官方样例选择一条右手手物姿态与它对应的原始 mesh，校验许可／单位／帧／接触，然后同输入跑三种 retarget。产出 public_data_adapter.md 与 raw / retarget 叠加图。没有与 cube 对应的示教时，该物体只用于 adapter 验收，不计入 cube 持物主表；不靠拉伸瓶子 mesh 冒充同一对象。

A2 · S03 的具体操作：方法可多，第一轮不全接

当前来源标签固定为 H-vector、H-angle、H-DexPilot、O-BODex、G-DRO；refinement 另列，人工 fallback 标 H-manual。本地 vector / angle 已有实现，但本协议下的候选尚待生成；其余方法在 adapter 通过前都是待适配。GraspADMM / CoToGrasp 放在综述的下一轮列表，不是额外强制 gate。

  1. 在看结果前分配 20 个 source-group slots：train 01–12、validation 13–16、test 17–20。一个源动作／模板衍生的所有变体归同一组；不同 seed 本身不是独立来源证据。实际源组不足则只做 smoke，不用复制补齐。
  2. 在同一手型、cube、包握类型、固定 PD 及初始化流程下生成，保留无解／超时／穿透失败 slot。每个方法记录 candidate 数及优化耗时；本轮单 slot 计算上限先设 CPU 120 s / GPU 120 s wall-clock，实际硬件和预算分别报告，不宣称等算力比较。超时即记失败，不换 seed 填坑。
  3. 直接 retarget 与 retarget + 优化修正分开行；人工编辑仅用于开发样本、记录次数与耗时，不能在 held-out test 上逐个调姿救活。
  4. 每个 train / validation 承重合格候选先跑 8 s 静态保持，再从相同初态分别跑 12 条标准 wrench probes：六向力 0.25mg、六向力矩 0.125mgr，t=2 s 开始、持续 0.32 s、两端 ramp 各 0.04 s，其余参数按 §6/§8。test slots 此时只导出封存，S08 解封后才跑同一来源评测。来源表保存静态与 12 条 probe 的逐条结果；这是事先固定的来源诊断集，不替代 controller 的封存测试集。
  5. 只用 train / validation 决定来源与参数。主 controller bank 优先用 H-vector；若承重失败，按记录转 H-manual 或已适配 O-BODex。换来源须保留旧失败与选择理由，后续 B0–B3 全部使用同一新 bank。
  6. test 侧只按冻结的初始化通过规则机械验收，不人为优化它的抓姿；全部初始化失败仍计入整体来源成功率。最终来源表与 controller 表分开生成。

A3 · S04 的裁判验收：以下检查全部通过才训练

  • 坐标：解析构造的刚性共同平移／旋转给出 ep、eR、vslip≈0；姿态四元数 q 与 −q 判同一旋转，90° cube 翻面判不同。解析测试容差 10⁻⁶；动力学 replay 的误差另外报告，不用解析容差要求两个 backend 接触轨迹逐位相同。
  • 动作：全零 residual 与 B0 控制目标完全相同；16 维 action 无法改变外部腕部命令；raw / clipped / measured 三者分别有日志。
  • 事件：分别注入触桌、接触丢失 0.12 s、hard-slip 超限 0.12 s、腕跟踪超限 0.20 s；验证失败一次记账，fail 与 complete 互斥，终止后不继续加奖励。
  • 奖励：用 §7 的解析输入得到理论上界 34、Kp(1 cm)=e⁻¹；记录每一成本原值和积分。NaN 注入触发 invalid 隔离，不进入 PPO buffer。
  • 物理：空手与带物体命令分别重放，比较实际腕轨迹、有效接触摩擦和执行器饱和；物体无 weld，手腕可有动力学驱动约束。换 backend / dt 后重新承重验收。
  • 分割：同 parent source、相邻示教帧、同一轨迹参数表不能跨 split。E4 的斜向／多轴轨迹禁止进入训练；训练的 mixed 指单轴腕运动 + 外力／参数组合，不是偷偷加入多轴腕轨迹。

§ 2不是不抓起来，而是先不学习“怎么抓起来”

固定流程负责闭合与抬起；学习控制器负责后面的 8 秒。两个控制器比较时，必须从相同且能真实承重的初态开始，而不是各自挑最有利的一次抓取。
  1. 准备候选。按 §3 得到一个 L20 包握 reference。使用现有 CubePick 资产中的方块：边长 0.07 m、质量 0.108 kg；不同时换场景和任务。
  2. 建立抓取。主入口采用固定初始化：reset 时允许临时定位物体；用 q_pre → q_hold 限速闭合 1.0 s，腕部保持，随后解除物体临时支撑并稳定 0.5 s。初始位置须使物体底部离桌 ≥0.10 m；解除后只能由手承重。完整桌面入口单独采用 gravity-on 的 pregrasp → 1.0 s 闭合 → minimum-jerk 抬高 0.15 m / 1.2 s → 0.5 s 稳定；腕部越界或无法离桌记初始化失败，不改成瞬移抬起。全过程动作经过真实模拟动力学。
  3. 解除所有支撑。物体底部至少离桌面 0.10 m；物体没有 weld、悬挂或其他隐形支撑。若只能在初始化时临时固定物体，必须先解除，再开始下面的检查。
  4. 稳定检查 0.5 s。使用固定 PD，不计训练奖励；没有桌面／地面接触、无明显穿透、无持续滑移。本版本窗口内相对平移漂移 ≤2 mm、相对旋转 ≤2°，末端相对速度 ≤0.01 m/s。先审计数值噪声；若阈值不适用，退回 S00 修改协议版本，不在单个失败样本上放宽。
  5. 记录初态。保存模型及参数 hash、完整积分状态、控制目标、初始化来源、reference 和重建说明；同一 backend 支持精确恢复。换 backend / 物理参数后必须重新稳定，不能假设原快照仍处于平衡。
  6. 开始计分。以稳定检查结束时的手—物体关系为固定目标，清空 episode 指标，运行 8 s = 200 个 25 Hz control steps。运动／外力只在计分开始后出现。

初始化失败单独记账。每个候选最多尝试 20 次；仍失败记为 initialization failure，不无限重采样。条件持物指标的分母是合格初态数，同时单列候选总数、初始化通过率与失败原因。比较 controller 时共用同一批初态；不能按每个 controller 的表现重新筛选。

两个入口。主入口是“已抓住状态 → 抗扰”，用于训练与归因；完整入口是“固定 pregrasp → 固定闭合／抬起 → 抗扰”，在本轮末期补验证。分别报告初始化、条件持物、完整流程成功率。桌面入口失败不会被从完整流程分母删除，也不等于一定是持物策略失败。

先用 1 个合格初态做 smoke，再用 3–5 个训练初态做 pilot；验证和测试各至少保留 1 个独立源组，所有增强继承 parent split。正式运行以 S03 的 manifest 为准，初态数量不足就停在 smoke，不靠复制快照制造“抓姿泛化”。所有 controller 恢复同一完整初态；DR 参数改变后按同一固定 PD 初始化，不能各自先用自己的 policy 闭合。

§ 3Reference 来源和 style 的执行规范

按 A1先执行本地 L20 vector；H-angle、H-DexPilot 是同输入对照。其他方法的可用性、数据库入口和优化器迁移步骤见选型综述的优先级表，不在本页重复论文名单。

  1. 本轮固定一个 cube 包握类型：记录拇指对向、参与手指、允许接触区域与原始意图。自然度不以肉眼“像人”代替物理承重。
  2. 所有 q 按 16 主动关节名存储，5 组耦合统一求 FK；人工标注、真实人手 retarget 和优化 refinement 分开记来源。
  3. 通过固定 PD 承重后冻结 q_ref=q_hold。在线 residual 仅在 §4 边界内修正，不能用每步更新 reference 隐藏动作漂移。
  4. 每个评测 episode 报类型保持与 contact-role 变化，成功但换成非预期类型另记 style failure。当前完成奖励不强行等于完整姿态模仿；新增 style reward 必须单独做消融。
  5. B0–B3 共用 reference 与状态；来源比较共用固定 PD。不可同时换生成器、初态和控制器后把增益全归给 PPO。

§ 4控制接口与物理：先固定这些，再调 reward

Policy 只有 16 维手指输出；腕部由独立轨迹驱动。Residual 是相对 reference 的有界偏移，不是逐步累加直到关节极限。
$$q_{\mathrm{raw},t}=q_{\mathrm{ref}}+0.15\,a_t,\qquad a_t\in[-1,1]^{16}$$

0.15 的单位是 rad，是本版本采用值，不是已测最佳幅度；所有 baseline 使用同一个允许目标集合。reference 按主动关节顺序存储，用关节名映射，不依赖 XML 隐含顺序。

$$q_{\mathrm{cmd},t}=\operatorname{clip}_{[q_{\min},q_{\max}]}\!\left[q_{\mathrm{cmd},t-1}+\operatorname{clip}_{[-v_{\max}\Delta t,v_{\max}\Delta t]}(q_{\mathrm{raw},t}-q_{\mathrm{cmd},t-1})\right],\quad v_{\max}=0.8\ \mathrm{rad/s}$$

关节范围与目标速率限制始终生效；记录 raw action、限幅后 command 和实际 q，避免把“输出很平滑”误当作“执行很平滑”。腕部 command 不经过 policy 修改。

§ 6干扰不是随便摇：先分开测，再混合

腕部运动模拟人怎么搬动物体；对物体施加外力模拟碰撞、阻力和负载。两类先分开，才能知道失败来自运动还是外接触。每次测试恢复初态，扰动的单位、坐标系、时间和实际实现值都记录。

6.1 Wrist trajectory bank

平移用世界坐标轴，旋转用 episode 初始 palm 的局部轴。使用起止速度、加速度为零的 minimum-jerk 段；在两个端点间往返并有随机停顿，不按轴顺序固定循环。

$$s(u)=10u^3-15u^4+6u^5,\qquad u=\operatorname{clip}(t/T,0,1),\qquad p(t)=p_0+A\,s(u)\,d$$

d 是单位方向；A 为位移，T 为单段时长。旋转用同一 s(u) 沿固定轴插值角度。检查真实加速度而非只看“移动了多远”：平移峰值速度为 1.875A/T，峰值加速度约为 5.774A/T²。

本版本训练分布：平移 A=0.02–0.10 m；旋转 10–30°；单段 T=0.8–1.6 s；段间停顿 0.2–0.6 s。限制平移加速度 ≤1 m/s²、角加速度 ≤5 rad/s²；超限轨迹重采样。训练腕部只用单轴段；mixed 指腕运动与 wrench / 物理参数同时出现，多轴／斜向腕轨迹专留 E4。所有轨迹须检查腕部关节范围和实际合成加速度，越界重采样并统计拒绝率。

6.2 External wrench bank

腕部静止，对物体施加六向力 ±x/±y/±z 和六向力矩 ±roll/±pitch/±yaw。坐标轴固定为 episode 初始 palm frame，并变换到仿真施力所需坐标。力作用于 COM；纯力矩单独施加。以后才加入离心接触点，因为偏心力同时产生力矩。

  • 脉冲：1–5 s 内随机开始，持续 0.24–0.48 s；上升／下降各 0.04 s，按 physics substep 平滑施加，不用理想瞬时冲量。
  • 强度：训练力幅值取 0.1–0.5 mg；力矩取 0.05–0.25 mgr，r=0.035 m 为固定报告尺度，不是解析抗扭能力。
  • 量纲核对：nominal m=0.108 kg、g=9.81 m/s² 时，0.5mg=0.52974 N；0.25mgr=0.00927045 N·m。质量改变后按当前质量换算，并同时报告归一化强度和实际 N / N·m。
  • 阈值扫描：另做单方向逐渐加力／加力矩，记录首次超限滑移强度；每个方向重置。到测试上限仍不失稳，报告“≥上限”，不假称测到了极限。

6.3 Physics randomization

nominal 有效滑动摩擦固定 μ=0.6、质量 0.108 kg；先在 S00 核对 contact pair 的实际值。B3 的 uniform DR 全程独立采样质量 nominal ×[0.8,1.2]、有效滑动摩擦 μ∈[0.3,0.8]；B2 不随机化二者。质量变更必须同步合理惯量，COM 第一轮固定。摩擦必须检查实际接触参数：不能只改 object geom，而手／物体的接触混合规则使生效摩擦仍是旧值。记录接触 pair 的实际 μ。

不同物理参数必须重新建立／稳定初态，并报告通过率；否则“只保留能初始化的低摩擦样本”会暗中改变任务分布。暂不同时随机 actuator gains、延迟、COM、对象形状和传感噪声。

§ 7Reward 1.1：具体算什么，为什么这样算？

主信号是“物体相对手掌没有滑走”，不是让物体停在世界某个点。移动手腕时，物体跟手一起运动应得高分；掉落、支撑作弊和失稳不能靠此前的累计 reward 算成功。

7.1 先定义测量量

$$T_{PO}(t)=T_{WP}(t)^{-1}T_{WO}(t),\qquad T^*_{PO}=T_{PO}(0)$$

W 是世界，P 是固定 palm site，O 是物体刚体坐标系；0 是通过稳定检查后的计分起点。目标关系在本 episode 内冻结，不能每步重设目标把累积滑移抹掉。

$$e_p=\|p_{PO}-p^*_{PO}\|,\qquad e_R=2\arccos\!\left(\operatorname{clip}(|\langle q_{PO},q^*_{PO}\rangle|,0,1)\right)$$

四元数必须归一化；绝对内积使 q 与 −q 等价。eR 使用 rad。方块仍按物体刚体坐标系记录旋转，90° 翻面不能因几何对称被当作“完全没滑”。

$$v_{\mathrm{slip}}=\|v_O-v_P-\omega_P\times(p_O-p_P)\|$$

所有速度和位置先统一到世界坐标，vO 是物体 COM 速度，vP 是 palm site 线速度。减掉叉乘项，才能使物体随手掌刚性旋转时得到零相对滑移；直接相减两个线速度会错误惩罚正常旋转。

7.2 每步奖励与一次性事件奖励

定义位置核 Kp=exp[−(ep/0.01 m)²]，旋转核 KR=exp[−(eR/10°)²]。以下每个 C 都归一化到 [0,1]；Δt=0.04 s。H=1 表示仍在计分阶段，非计分初始化不调用本 reward。

$$r_t=\Delta t\,[H+2K_p+K_R-0.20C_v-0.05C_{\mathrm{ref}}-0.02C_{\mathrm{slew}}-0.10C_{\mathrm{effort}}-0.50C_{\mathrm{sat}}]-5I_{\mathrm{fail}}+2I_{\mathrm{complete}}$$

括号内是每秒收益／成本，乘 Δt 后不同控制频率的物理时间可比较；失败 −5 和合格完成 +2 只在事件发生时记一次，不乘 Δt，不在终止后继续累积。fail 优先于 complete。

不必第一轮就跑完所有诊断：B0/B1 无法静态持物，先停；B3 表现差，再看 D2；想验证旧自主专家能否复用，再跑 D1。Teacher / student 只有在样本效率或观测迁移的实际缺口出现后进入下一版。

§ 10训练顺序与预算：每一段都能停止

先验证环境，再做小预算曲线；不要直接跑满 100M steps。以下是本版本采用的训练设置，需在实现项目落实并导出实际配置；不是已存在的启动脚本，也不要求真人在线。
  1. T0 无学习验收。固定物理参数，跑 B0/B1 静态及小扰动；先取得可复现的初态和 baseline 视频。
  2. T1 Smoke。单个 nominal 初态，静止／低幅运动，1M environment steps，seed 0。只验证 reward 有限、action 权限正确、终止和日志正确，不宣称泛化。
  3. T2 Nominal pilot。3–5 个训练初态，B2 的预算为 10M steps/seed。前 1M steps 为静态／低幅运动预热，随后 1M–10M 按完整训练分布执行；验证初态不进训练。
  4. T3 DR pilot。B3 使用与 B2 相同网络、预算和场景课程，全程采用 §6 的 uniform mass / friction DR。两者前 1M steps 固定为 50% 静态、50% wrist-only（A=0.02 m、旋转 10°、T=1.6 s），后续固定为 20% 静态、30% wrist-only、30% wrench-only、20% 混合；只有物理参数分布不同，不看 test 调课程。
  5. T4 配对验证。每 1M steps 在固定验证集评估；按照持物完成率优先、再看严格稳定率和 effort 选 checkpoint，不按最高训练 reward 选。
  6. T5 三 seed。seed 0 通过环境与 nominal gate 后，复跑 seeds 1、2；10M 为默认终点；若任一方法 seed 0 在 8M/9M/10M 三次验证的主要 stress 完成率单调上升且总增益 ≥5 个百分点，可启用 20M 扩展。启用则 B2/B3 的全部 seeds 使用同预算，分别报告 10M 与 20M；不能只延长落后方法后仍称等预算。否则先诊断。超过此预算重新立版本决策，不自动无限加算力。

§ 11测试集、过拟合与真正的第一张表

现在就隔离测试，不现在就要求跨一切。先证明同一个物体在未见轨迹／扰动组合上有效；单物体结果不能写成“跨物体通用”。

验证集固定 96 episodes（E0–E5 各 16 条）；最终 test 192 episodes，分为以下 6 组、每组 32 条。训练随机数 seed 范围 0–99,999，验证 200,000–299,999，测试 300,000–399,999；这仅用于避免随机流重用，不能替代初态来源、轨迹类型和物理参数组合的实质隔离。

每个 controller 共用冻结的 scenario manifest，test 不参与调参
组测试内容泛化声明
E0Nominal 静态保持，初态变体基础 sanity
E1ID 范围内未见 wrist 轨迹参数／组合同分布未见轨迹
E2ID 范围内未见 force / torque pulse同分布未见扰动
E3ID 范围内未见 wrist + wrench + 物理参数组合组合泛化

E5力 0.5–1.0 mg 或力矩 0.25–0.5 mgr，其余受控强度 OOD，只测承受范围，不保证必须成功

每条 manifest 必须保存初态来源/hash、物理参数、轨迹或生成器版本、所有扰动时刻及幅值、数值设置。对 train 与 test 做实际参数／轨迹重复检查；反复查看 test 视频并据此调模型也算 test 泄漏。

结果表的列：initialization acceptance、条件持物完成率、strict stability、失稳／掉落／腕部失败／数值异常数量、ep/eR peak 与 P95、恢复率／恢复时间、effort P95、饱和比例。报告每个 seed 和每个组，不只合并平均；小 pilot 不包装成大规模统计证明。

分母固定：N_attempt 为 manifest 中计划的 scenario 次数，N_init 为固定初始化通过次数，N_success 为持物完成次数；初始化通过率=N_init/N_attempt，条件持物完成率=N_success/N_init，完整流程率=N_success/N_attempt。初始化后的 numerical invalid 保留在 N_init 中但不计成功，同时报告 invalid 数；N_init=0 时条件率写 N/A，不写 0%。来源生成表另外报告 raw slots、几何有效、承重有效数量，不把优化无解混作一个已执行的持物 trial。

配对重采样同一 scenario ID 比较 B3−B0/B1，报告 95% bootstrap CI；有多 training seeds 时以训练 seed 和 scenario 分层，并保留每 seed 原始值。3 seeds、每组 32 条只能用于方向判断，最终论文规模在下一版确定。掉落 episode 不因无法计算后续滑移而从成功率分母删除；只对成功者计算的滑移统计要明确标注条件。

扩展顺序：Stage 1.1 内看未见运动；Stage 1.2 加圆柱／偏心物体与完整抓取入口；以后再做 held-out object instance / category、未见操作者和未见任务。公开数据库要先按人／物／序列切分，再 retarget，不在 retarget 后随机打散。
