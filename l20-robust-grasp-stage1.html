改意图、置信度与手势库：现在考虑到哪里？

现在保留事件与失败案例，先完成单一回归基线。意图可以随时间改变，预测只表示当前证据下的判断；不要求系统预知用户尚未表达的改变。当前影子手不参与控制，分类层、置信度校准与动态辅助都不作为采集前置。

改意图与取消：怎样记录，怎样避免错误标签？

区分“从两指改为三指”“停止抓取”“已持物后要求释放”，不能把三者都当成低置信度。首轮可另留少量有提示的改意图／取消诊断片段，记录提示时间、用户报告和可观察动作变化，三者不等同于直接测到内心意图。与固定意图主测试分开计数，未采集时标待执行。

若轨迹原本朝 A，途中改成 B，不能把 A 阶段的所有历史窗口都配成 B；按有依据的阶段标注，过渡区保留不确定，不清楚时不用于固定意图监督。取消片段可以没有抓姿终点，仍保留原始记录。未来用最近时间窗、允许目标转移的滤波或变化检测更新判断，避免旧历史和强平滑锁住 A；评估改意图后的更新延迟、旧目标持续输出与误报警。

接入共享控制后，明确取消／用户覆盖应撤销旧目标与相应辅助，不必等待置信度下降。已承重时停止自动继续任务与立即张手是不同动作，释放按独立的明确指令处理；不能用“防掉落”永久阻止用户释放。

回归怎样输出可信度？是否先分类再回归？

可信度首先定义为“在给定预测时距、意图保持条件和姿态容差下，预测落入容差的可能性”。分别看追踪有效性、目标预测不确定性与几何／执行可行性，不能用一个数互相替代，也不能用离物体近直接推出高置信度。

得到回归基线后，可比较多个独立训练的小回归器的分歧，并结合条件残差或预测区间估计误差。模型一致仍可能共同预测错误或共同输出平均手形；分歧不是概率，也不完整描述多个合理未来。必须在独立校准／验证示教上检查区间覆盖、误差与拒绝预测后的覆盖率，在未用于校准的测试集报告；训练外姿态和改意图需要单独测试。未实现校准时不显示虚构的置信百分比。方法参考 Deep Ensembles（Lakshminarayanan 等，NeurIPS 2017）。

可以保存有限的模板／示教库用于覆盖采集、检索基线与优化初始化；人类具体抓姿的关节、掌姿和接触位置连续变化，有限 taxonomy 不等于全部姿态有限。GRASP taxonomy（Feix 等，2016）整理 33 种静态稳定抓取类型，本轮不据此强制采齐或固定类别数。

“先分类类型，再回归类型内姿态”是候选层级模型，可能减轻跨类型平均化，也会引入分类错误传播、边界跳变和未见类型拒识问题；softmax 最大值不能证明目标在已知库内。先保存有用的采集标签；只有基线显示可辨识类型被持续混淆，再按相同数据划分比较直接回归与类型条件回归。若保留多个候选，不把不同手形的关节直接平均成一只手。关于已知意图库外仍可能过度自信，参见 Situational Confidence Assistance（Zurek 等，ICRA 2021）。

如何交给后续抓取模块？

意图输出作为目标参考与偏好传给抓取模块。抓取模块还需要物体几何、当前机器人状态与执行约束；只有接触点不够。第一版接口直接传完整预测抓姿，接触偏好作为可选字段，以后可以替换预测器而不改变下游职责。

IntentGoal: object/frame/time + target_palm_pose + target_q
optional contact_preferences: link_id + surface_region + normal + tolerance + intent_status
GraspRefiner(geometry, robot_state, IntentGoal) → feasible_goal / unresolved
GoalController(robot_state, feasible_goal) → current_action

intent_status 区分“偏好接触／明确避开／未知”；容差表达允许移动多少，不是已校准的概率。确定性回归基线没有天然置信度，若未来加入置信度须单独验证，缺失时留空。所有目标带时间和有效性，过期或未解出的目标不能直接用于增强辅助。

后续讨论：尽量接近接触偏好，怎样产生并执行抓姿？

拟议路线，未开始训练，也不作为 Stage 1.1 的前置验收。先让一个几何修正器接受人工确认的目标，检验 L20 能否在附近找到可行姿态；再讨论学习执行。这样可以先区分目标本身不可行与意图预测错误。

把“精确点”放宽成物体表面的局部区域：拇指可以在偏好区域内调整，食指和中指各自保持对应区域。区域不能因欧氏距离近就跨到 cube 的另一面；保留表面部位／法向。手指的接触身份与位置容差分别控制：允许接触点微移，不等于允许把两指捏合改为五指包握。明确禁止接触的部位应有避让约束；不确定的部位保留未知。

minimize over g: pose_deviation(g, ĝ_T) + contact_region_error(g) + normal_error(g)
subject to joint_limits, coupling, nonpenetration, explicit_avoidance

这是待设计的目标结构，不是已定权重。用 L20 FK／接触面计算每个指定部位到其目标区域的误差；手形与掌姿参考用来约束接触位置之外的自由度。法向项要求接触面朝向合理。几何投影与限位检查不证明力学稳定，后续才加入摩擦／wrench 与物理执行评测。无解时报告偏离、约束冲突或未找到解，不能自动替换为另一种抓法。

修正器首先可以不训练。已有 grasping/optimization/planner 有接触距离、穿透与关节成本，但默认 ORCA；L20 的关节耦合、接触部位及模型仍需适配。现有 L20 retarget/FK 可以复用，资产存在不等于上述新接口已实现。

纯数学能否抓举？可以用接触约束 IK／优化求抓姿，按已知接触、摩擦、质量与质心求满足物体力／力矩平衡及驱动能力的接触力，再用模型式反馈控制执行。固定接触下，线性化摩擦锥可形成 QP；保留圆锥约束通常是 SOCP。给定 mesh 不等于知道摩擦、质量和真实接触力，静态算出的力也不会自动成为电机实际施加的力；L20 耦合与位置控制接口需单独考虑。

动态调整同样可以使用阻抗／力反馈、在线接触力重分配或 MPC，不强制训练神经网络。接触切换和抬起的加速度需要动态模型与状态反馈，静态平衡不保证整段动作成功；参考 Complementarity-Free Multi-Contact Modeling and Optimization for Dexterous Manipulation（2024 预印本） 的模型式接触 MPC。仿真可读取真值作首个基线，未来实机要明确哪些量可测／可估。只有计算时延、模型误差或泛化问题暴露后，再考虑学习加速、残差补偿或 goal-conditioned policy；物理模型与学习模型都不能无条件保证抓稳。

若后续训练执行 policy：输入当前关节／速度、掌与物体相对状态、修正后的目标抓姿，必要时附接触区域与接触观测；输出当前关节增量或有界残差。先在同一 cube 上准备多个可行目标及其接近／闭合过程，以目标条件监督学习作基线；需要稳定持物时再用带目标跟踪约束的 RL 或其他闭环方法。只有静态接触点没有动作标签，不能直接监督训练轨迹 policy。

训练时变化目标抓姿与起始状态，保留手指组合和接触偏好，并对单独留出的目标分别评价执行效果与意图偏离。只奖励“拿起”，可能让策略忽略目标而总用最容易的抓法；不能只看总成功率。先验证人工正确目标的执行，再输入有预测误差的目标。目标姿态可行不保证从任意初态都有无碰撞路径。

允许同期准备的最小工作：统一坐标、对象／手模型版本和目标接口；从已确认终点可视化接触候选；用人工目标离线检验少量 L20 几何修正案例。robust policy、跨物体训练和在线学习保持后续议题。实时新观测更新预测是 online inference，不等于在线更新模型参数。

以后接共享控制时，先把最终目标转换为当前时刻的短步参考，再与同空间、同时刻的用户指令融合；腕部先保持用户控制。当前张手与预测最终闭手不自动构成冲突。错误预测、用户撤销与目标不可行时应退让，不能只因接近物体就提高权重。

方法依据：GenDexGrasp（Li 等，ICRA 2023）展示接触图 → 优化抓姿；UniDexGrasp（Xu 等，CVPR 2023）区分抓姿生成与目标条件执行；CoToGrasp（Merand 等，ECCV 2026）研究指定接触拓扑下的生成。这些是接口设计的参考，不是已经适配 L20 的实现，也不证明任意接触点均可执行。代码与适配缺口见抓姿来源综述。

这一轮交付什么？

10 条不入训练的试跑、240 条有效固定意图示教、24 条改意图／取消诊断、冻结的 trial manifest、144／48／48 session 划分、字段与坐标说明，以及抽样回放验收记录。排除的 trial 仍保留原始记录和原因；每种手形、方向、位置与 session 的有效数量必须可核对。

进入 Stage 1.2 的门槛：关键时间序列可回放，输入与终点标签能在 cube 坐标系重算，tracking fault／取消不会被当作正常抓姿，任何 trial 的帧和窗口不会跨 train／validation／test。这里不要求模型指标或影子手视频。

所有采集状态仍为待执行。初次单用户 cube 数据不能推广为跨用户、跨物体、意图预测或稳定抓取能力。

抓姿／优化工作在 Dex_Hand/grasping，控制与实验在 Dex_Hand/human_machine_interaction。Handbook 只保留计划与结果摘要。

本轮边界与后续

Stage 1.1 不训练模型，也不做稳定性、承重、抗扰、pick 或精确接触点预测。它只保证数据与标签可信。确定性 MLP、Flow Matching、误差／提前量图和影子手候选验证属于 Stage 1.2；robust grasp 仍是更后的能力线。

抓姿来源按需查文献库，其他训练方案按共享数据与并行对照协议逐条接入，不要求 Stage 1.1 在采集前决定最终模型。

旧固定 PD 承重方案已退出当前短期路线，旧稿保留在 Git 历史，不是数采验收要求。
