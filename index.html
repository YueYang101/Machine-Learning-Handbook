工具TOOLS

自用的远程连接指令，私有页面仅登录可见。点右侧「复制」直接粘贴。带 ssh 4090 / nas-lan 别名的命令需本机 ~/.ssh/config 已配（Mac 已配）；换设备需先装好对应密钥。

4090 主机 · 远程唤醒

机器睡眠/关机时先发魔术包（由家里常开的 NAS 广播），约 15–20s 上线。

在家里（Mac 连着家里网络）
ssh nas-lan /usr/local/sbin/wol.sh 4090
在外网（不在家里网络，走 Tailscale）
ssh -i ~/.ssh/id_rsa -p 2222 dev@100.113.248.42 'ssh 13137836541@172.19.0.1 /usr/local/sbin/wol.sh 4090'

连接

Tailscale（人在哪都能连）
ssh 4090
家里 LAN（更快）
ssh 4090-lan

验证

确认是魔术包唤醒（应显示 Realtek 5GbE）
ssh 4090 'powercfg /lastwake'
看 GPU
ssh 4090 'nvidia-smi'

  • 判断在家/外网：先试 ssh -o ConnectTimeout=4 nas-lan true，通=在家用家里命令，不通=外网命令。
  • 外网必走 Tailscale：LAN 地址（192.168.100.1 / 192.168.0.178）在外面够不着——探测失败≠NAS 挂了。
  • 钥匙不同：进容器用 id_rsa，进 NAS 主机（nas-lan）用 id_ed25519_nas，别用混。
  • Tailscale SSH 直登 NAS 主机被 ACL 拒，外网只能经容器跳 172.19.0.1。
  • wol.sh 不需 sudo；唤醒后轮询 ssh 4090 exit 返回 0 即上线。
  • 远端跑 PowerShell 不要再套 powershell -Command "..."（默认 shell 已是 PS，引号会打架）。
  • 密码登录不可用（用的是开机 PIN，网络登录不认），一律用密钥。

关机（S5）唤醒尚未实测；睡眠已通过。若关机唤不醒，进 BIOS 确认 ErP=Disabled、Wake on LAN=Enabled。
