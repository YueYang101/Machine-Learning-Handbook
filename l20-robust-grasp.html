0. 核心判断

以下是项目决策，不是已经得到的实验结果。

联合训练可保留，但不能把“部署时直接丢掉 wrist action”当作默认可迁移。

现有 joint wrist+finger PPO 最有价值的角色是 teacher、抓姿与轨迹数据生成器，以及 full-control upper bound。部署控制器应显式地在“人控 wrist”闭环里训练或蒸馏。

V1 的实验主线

L20 grasp bank → joint teacher → wrist-intervention teacher → exogenous-wrist finger student；再以 mask-conditioned policy 作为结构较小的对照。

研究对象

不是“shared control 算法”，而是 human-motion-conditioned grasp stabilization。

最可能的贡献

L20 欠驱动手 + 真实人腕轨迹 benchmark + 低维触觉历史 + tail-risk 鲁棒执行。

不能靠什么解决

仅增加物体数、摩擦随机化和 PPO steps，无法修复 action mismatch、不可观测动力学与 sim-to-real 误差。

论文新颖性警告 “多物体 + 摩擦随机化 + 外力扰动 + PPO”已经不足以形成强方法贡献。RobustDexGrasp、Grasp-to-Act、TacDexGrasp 与假肢共享控制工作已经覆盖了其中大部分元素。你们需要把 人控 wrist 的执行分布、L20 传感器约束、低尾鲁棒性和真实硬件验证 做成不可替代的部分。

1. 训练控 wrist、部署人控 wrist：会不会崩？

答案是：网络不会因为“少执行 6 个输出”而数值崩溃，但闭环行为可能突然失效。问题发生在动力学和 credit assignment，而不只是 action tensor 的形状。

训练：aᵗ = [aᵂ_π, aᶠ_π]，sₜ₊₁ ~ P(sₜ, aᵂ_π, aᶠ_π) 部署：aᵗ = [aᵂ_H, aᶠ_π]，sₜ₊₁ ~ P(sₜ, aᵂ_H, aᶠ_π) P_train ≠ P_deploy。即使 finger head 的代码完全不变，它看到的状态分布也已经改变。
风险具体表现如何检测
腕部“抢功”策略用 wrist 对齐、减速或反向补偿，手指只提供最低限度夹持。冻结 finger / wrist 分别做 action ablation，测 reward 和保持率的下降。
状态分布外移人的 jerk、相位和停止方式不在 joint policy 自己产生的轨迹上。在冻结人腕 test bank 上比较特征距离、失败率和不确定度。
动作协同被切断手指动作通过长期状态与 wrist 策略共同形成；丢弃 wrist 后，原有时序协同消失。保持初始状态相同，逐步增加 wrist override 比例，绘制性能曲线。
共享表示干扰共享 trunk 更偏向优化高回报、易控制的 wrist action，finger 表示不足。比较 monolithic head、shared trunk + two heads、完全独立 encoders。
反应太晚只有 wrist pose、没有速度/加速度或即将执行的命令，惯性载荷出现后才补救。ablate actual kinematics、command preview 和 0.2 s history。

三种实施方式

方案训练部署判断
A. 直接丢弃100% 由一个策略执行 wrist + finger只执行 finger，wrist 输出丢弃高风险 只能作为 zero-shot baseline，不能作为主方法。

C. Joint teacher → finger student先全控制训练 teacher；student 在实际会遇到的外生 wrist 闭环里蒸馏并 RL fine-tunestudent 只输出 16D finger residual推荐 部署接口与训练接口一致，最容易解释。
若“训练时 100% 必须由模型执行 wrist”是不可改的硬约束 那么只能诚实地把它当作 domain-transfer 假设，并依赖零样本压力测试；没有算法能从原则上保证在人类 wrist 分布下仍稳定。至少需要：分离 wrist/finger 网络头、把真实 wrist 状态作为 finger 输入、对 wrist action 加强随机扰动，并预先规定可接受的人体运动包络。

推荐的混合执行公式

m ~ Bernoulli(p) # 以 episode / phase 采样，不逐 timestep 闪烁 aᵂ_exec = m · aᵂ_π + (1-m) · aᵂ_exo aᶠ_exec = aᶠ_ref(g) + clip(Δaᶠ_π, -δ, δ) 训练课程：p = 1.0 → 0.7 → 0.3 → 0.0；最后阶段 100% rollout 使用完整外生 wrist 轨迹。 部署：p = 0，aᵂ_exo 来自 Quest / 人体；finger policy 总是读取实际 wrist 运动。

不要逐 timestep 随机抖动 mask；那会制造不真实的控制权切换。以 episode 或明确 phase 为单位切换，并在策略输入中提供 control_mode。人的 wrist 应通过动态 wrist body 的 servo / soft constraint 实现，不要直接覆写 qpos。

PPO 实现细节：只优化实际执行的 action AUTO 模式可在 wrist + finger 全维度上计算 PPO log-prob / entropy / ratio；HUMAN 模式中，wrist 输出没有进入环境，PPO loss 必须只在 16 个 active finger 维度上计算。否则未执行的 wrist 随机维度会影响 clipping 和梯度，却没有对应的因果回报。建议使用两个 action heads 和显式 active-dimension mask，而不是事后把一个 monolithic distribution 的 wrist 维度置零。

3. 人类参考抓姿何时进入？从 teacher 训练之前进入

答案是“需要尽早用”，但准确角色不是直接给最终策略做行为克隆。先把人手数据转换成 L20 原生、物理可行的 grasp goal / seed bank，之后 teacher 与 student 都围绕同一目标学习。

关键结论 人类数据应在离线抓姿库阶段进入：先按人和物体拆分数据，再做 L20 retarget 与 MuJoCo 物理筛选。它给出自然的 mode、contact 与目标姿态；PPO 负责把这些目标变成动态可执行轨迹。若等 teacher 训练完才加入自然度，teacher 很可能已经收敛到稳定但机械化、接触模式单一的局部最优。
G0 · Split按 human subject + object instance 先拆 train / val / test；保存 intent、object-frame contacts 与 pregrasp。
G1 · Retarget只优化 L20 的 16 个 active joints；5 个 passive joints 由真实 coupling 函数生成。
G2 · Screen检查可达、穿透、关节余量、重力保持、12 方向 wrench、力与电流上限。
G3 · Bank按 mode + contact + palm + joints 聚类，每个 object / mode 固定保留 3–5 个候选。

先保存“物体坐标系里的意图”，不要保存人手关节角答案

每条记录 = {intent / mode, q_pre, q_goal, object-local contacts, palm pose, fingertip / phalange vectors, source, naturalness score, robustness score} q_passive = coupling_L20(q_active) min_{T,q_active} λc E_contact + λf E_fingertip + λp E_palm + λo E_orientation + λj E_joint-margin + λs E_self-collision + λx E_penetration

MANO、Shadow Hand 与 L20 的骨长、关节轴、拇指工作空间和耦合关系不同；直接最小化 human joint-angle MSE 会得到“数值接近、接触错误”的姿势。主目标应是 object-frame 接触锚点、掌—物体变换、指尖/指节相对几何和 grasp mode。

先验如何进入 teacher / student

T0
Goal-conditioned joint teacher：每回合从 PH / PR / PM 采样 g=(q_pre,q_goal,contacts,mode)。可有 20–30% 回合从 pregrasp 邻域启动；其余仍从完整初始状态。接触前弱 pose/contact shaping，接触后快速衰减，允许为稳定而偏离人类目标。
T1
Wrist-intervention teacher：逐步提高外生 wrist 比例。用于 student 的专家动作只从高 intervention、尤其 100% human-wrist rollout 采集；不能用 teacher 自己选 wrist 时的 finger action 直接监督 student。
S0
Distillation warm start：student 读取部署可得的 proprio、tactile、actual wrist history 与 goal，只输出 16D finger residual。人类 pose 仍是 goal，不是强 action label。
S1
External-wrist on-policy fine-tune：在 100% 外生 wrist 闭环继续 RL / DAgger 式迭代并退火 imitation loss；最终优化部署状态分布。
与现有 PPO → diffusion 流程的接口 若后续 diffusion / flow policy 学“递水”和“喝水”的多模态 nominal action，训练数据也应来自 T1 的 100% 外生 wrist rollout：保留与用户 wrist、mode、goal 配对的 finger trajectory，丢弃 teacher wrist action。生成模型负责多模态名义抓姿/动作段，低层 recurrent tactile student 负责闭环稳定；不要让 diffusion 同时承担选意图、跟人腕和防滑三件事。

4. Teacher / student 控制实验

保留 current joint policy 的价值，同时让最终 hand controller 的训练闭环与 inference 对齐。

T0 · Joint teacher控制 wrist + fingers，以 L20 grasp bank 为 goal，建立 full-control upper bound。
T1 · Intervention外生 wrist 从 β=0 逐步升到 β=1；teacher 适应人的闭环状态分布。
S0/S1 · Student蒸馏 β=1 的 finger action，再在 100% external wrist 下 on-policy fine-tune。
Deployment人的 wrist 被实际执行；student 只输出 16D finger residual 在线稳定。

从旧 checkpoint 迁移时，可以拷贝 finger encoder/head 作为初始化，但 joint teacher 的 critic 必须重训或重置：wrist 被干预后 transition 和 return 都已改变。teacher finger action 只作为早期、逐步衰减的 imitation prior；仅在 teacher-controlled wrist 状态上做离线 BC，仍会保留 occupancy mismatch。

Δaᶠₜ ~ πθ(o_deploy, hₜ, g) o_deploy = [q₂₁, q̇₂₁, aᶠₜ₋₁, tactile, wrist pose/vel/acc, tracking error, control_mode] qᶠ_target = qᶠ_grasp(g) + Δaᶠₜ Privileged critic only = [object pose/velocity, μ, mass, COM, contacts, disturbance wrench]
a_w^exec = (1 − β) a_w^T + β a_w^human, β: 0 → 1 β = 1 时：wrist head 可保留作 auxiliary prediction， 但 PPO log-prob / ratio / entropy 只计算实际执行的 16D finger action。
不能从 T0 自动 wrist 轨迹直接蒸馏 student 那些 finger action 与 teacher 自己选择的 wrist 强耦合。Student 的 action label 必须来自 T1 高 β、尤其 β=1 的 rollout，或在 student 自己诱导的 external-wrist 状态上通过 DAgger / on-policy correction 重新收集。

为什么用 residual

  • 保留 pose library 的多样性和自然度；
  • 限制探索范围，避免“少数手指硬夹”的仿真局部最优；
  • 与 L20 的 16 个可执行 position targets 一致。

为什么用 GRU / history

  • 质量、摩擦、COM 与触觉延迟是 hidden state；
  • 瞬时观测无法区分“刚开始滑”和“稳定轻触”；
  • 0.1–0.3 s 历史可作为小型 online system identifier。

若 Quest 的未来目标能在物理执行前获得，可额外输入 50–100 ms command preview 做 feed-forward。必须同时输入实际 wrist kinematics 和 target-tracking error，不能把被丢弃的 policy wrist action 当作“实际 wrist”。

5. L20 触觉在 MuJoCo 里的实现

难点不在“能不能读 contact force”，而在于真实 L20 批次的传感器规格不透明，以及如何把仿真接触降维到真实可部署的信号。

先做硬件审计

官方公开接口存在至少两类表示：旧式每指聚合的 20 维 force/proximity 数据，以及矩阵式 4×10 或 6×12 数据；当前 C++ 文档示例为五指 5×6×12、共 360 个 uint8 值。公开文档没有给出可靠的 N/LSB、带宽、滞后、漂移、串扰和温度曲线。因此先确认你们实际批次的 touch_type、topic shape 和 timestamp，不能从 SDK shape 推断物理精度。

MuJoCo 方案得到什么成本建议
<touch>site 体积内法向接触力之和低可作最简 Fn baseline；没有 shear / CoP。
<contact reduce="netforce">聚合 contact wrench、位置等固定输出低V1 推荐；转到每个 fingertip site 的局部坐标。
mj_contactForce逐 contact 读取 6D wrench，自行聚合低–中旧版 MuJoCo 或需要自定义筛选时使用。
touch_grid plugin空间 grid，可输出 normal / tangent / torsional channels中V2；当前 MJX-Warp 对 sensor plugin 的支持是关键阻塞。
SDF tactile / flex skin更稠密的几何压力或软皮肤近似高只有当皮肤力学本身是研究贡献时才做。
 
<site name="thumb_pad" type="box" pos="..." quat="..." size="..."/>
<sensor>
  <contact name="thumb_tactile"
           site="thumb_pad"
           data="found force torque pos"
           reduce="netforce"/>
</sensor>

V1 每指只给策略 4 个派生量：[contact, log(1+Fn), CoP_x, CoP_y]，五指共 20 维。若真实切向信号完成标定，再加入 Ft_x, Ft_y。Dense matrix 的现实映射可写成：

pᵢⱼ = max(0, gᵢⱼ(rawᵢⱼ − bᵢⱼ)) Fn = Σ pᵢⱼ CoP = Σ(pᵢⱼ · rᵢⱼ) / (Fn + ε)

sensor wrapper 必须模拟：sample-and-hold、FIFO latency/jitter、低通、per-taxel gain/bias、deadzone、8-bit quantization/saturation、dead taxel、dropout 与相关噪声。MuJoCo XML 的 sensor noise 字段不能替代完整运行时噪声注入。

触觉消融阶梯

  1. Proprio only；
  2. binary contact；
  3. 五指 normal force；
  4. normal + CoP（V1 主方案）；
  5. normal + CoP + shear；
  6. 6×12 spatial tactile + CNN（只有前一步证明有必要才做）。

这条阶梯能回答“高分辨率触觉是否真有用”，避免先投入高成本皮肤仿真，最后只学到总压力。

6. V1：L20 Robust Hold Benchmark

目标是先做一个最小但足够难、可复现、能暴露 action mismatch 的刚体抓持实验。所有数字都是建议的起始协议，需被真实 L20 额定负载和 Quest 轨迹校准。

V1 明确包含

  • 单个刚性、非易碎物体；
  • 外部给定 grasp reference / pre-grasp；
  • 联合 teacher 控 wrist+finger；
  • 外生 wrist student / override eval；
  • 几何、质量、摩擦、static COM；
  • 程序化和真实人腕轨迹；
  • 16D finger residual action；
  • 低维 fingertip tactile ladder；
  • 严格 ID / OOD / corner splits；
  • MuJoCo 为唯一物理权威。

V1 明确不包含

高保真液体、可变形纸杯、功能性工具使用、筷子双物体操作、视觉语义和端到端任意位置抓取。它们不是不重要，而是与 V1 的 failure cause 不可同时辨识。

Reward：先稳住，再谈最小力

rₜ = w_hold·I(held) + w_p·exp(−||e_position||/σp) + w_R·exp(−θ_rotation/σR) − w_v·||v_object/palm||² − w_Δa·||aₜ − aₜ₋₁||² − W_drop·I(drop) − w_over·Σ[Fn − F_hardware]₊²

不要在 V1 把“最小抓力”设为主奖励：模拟器可能允许非常慢的滑移。object pose、slip 与 privileged contact 可以用于 reward / critic，但不能进入 deployable actor。自然度单独画 robustness–naturalness Pareto，不与稳定性混成一个分数。

7. Baselines、消融与统计

必须有的控制基线

组方法用途
B0Fixed PD / tuned fixed grip最简单的部署 sanity baseline。
B1Max-safe closure若它已达到 95%，RL 的 rigid-hold 贡献会很弱。
B2Static grasp optimizer + PD/impedance分离“好抓姿”与“动态学习”的贡献。
B3当前 nominal joint PPO复用现有结果，跑 T0 β=0 / direct β=1。
B4PPO + uniform domain randomization“堆场景/算力”基线。
B5Tactile slip reflex假肢/工业上非常强的规则控制基线。
B6Mask-conditioned joint residual PPO最小架构修改。
B7Joint teacher → recurrent finger student推荐主方法。
B8Privileged oracle actor只做上界；判断 observation 是否不足。
B9SOCP friction-cone controller只有 L20 有可靠 3D shear 时才完整实现。

核心消融

  • no wrist kinematics；
  • no command preview；
  • no history / GRU；
  • absolute vs residual finger action；
  • P0 None vs PH Human vs PR Robot vs PM Mixed；
  • no friction DR；
  • no wrist override training；
  • uniform vs failure-aware sampling；
  • symmetric vs privileged critic；
  • contact → Fn → Fn+CoP → shear。

严格成功定义

  • 抬升 0.10 m、无桌面或环境支撑，之后保持 5 s；
  • settling 0.25 s 后，object–palm translation drift <20 mm；
  • rotation drift <15°；对称物体使用 symmetry-aware angle；
  • 无持续 actuator saturation、接触穿透异常或力安全违规；
  • 同时报告宽松的 no-drop success，不能只报 reward。

主指标

类别指标
成功acquisition、lift、strict 5 s hold 分开；time-to-slip / drop。
人腕鲁棒性success–severity curve；critical linear/angular acceleration、jerk 与冲击恢复率。

正式实验建议至少 5 个 training seeds；冻结 test scenario bank；每 method / seed 约 2,000 个 held-out episodes；paired evaluation；以 object 为第一层、trajectory 为第二层做 hierarchical bootstrap，报告 95% CI。

Go / no-go gates

Gate门槛失败后做什么
G0 环境有效nominal ≥90%；官方 solver 下无异常能量；dt audit 不改变排名。先修 MJCF / contact / actuator，不训练新方法。
G1 学习必要fixed/max-safe baseline <95% stress success。若 ≥95%，转向 fragile / minimum-force / tactile recovery。
G2 mismatchT0 direct β=1 对 T0 β=0 的 gap 在 ID ≤5 points、OOD ≤10 points。超标则 T1 intervention adaptation / finger student 必须进入部署路线。
G3 方法有效ID ≥85%、OOD ≥70%、worst 10% ≥50–60%；相对 uniform DR ≥10 points 或 failure 降 ≥30%。检查 curriculum、history 与 wrist distribution。
G4 observationoracle 对 deployable actor gap ≤15 points。超标说明缺 sensor / latent estimator，不是缺更多 PPO steps。
G5 grasp priorPH 提高 held-out 自然度；PR 给稳定上界；PM 在相对 PR ≤5 points 的 non-inferiority margin 内显著提高自然度。若 PH/PM 无自然度或 diversity 增益，不扩大真人采集；先检查 retarget / metric。

液体与易碎物体的物理边界

F_required ≈ ||F_tangential|| / μ 可行条件：F_required ≤ F_damage 若人的加速度使防滑所需法向力超过损坏阈值，任何 RL 都无法同时满足“不掉”和“不坏”。 只能换抓姿 / 增加接触面积与顺应性 / 降低腕部加速度 / 给用户反馈。

9. 这不是只堆算力的问题

1POMDP

μ、质量、COM、液体相位不可直接观测。需要 history / recurrent belief 或显式 latent dynamics estimator。

2Risk

平均成功率会掩盖重物体+低摩擦+高 jerk 的组合失败。优化和报告 CVaR / worst-group。

3Constraint

fragile 不是 reward tuning；需要 force constraint、CBF、QP/SOCP 或 action projection。

4System ID

触觉、actuator、delay、backlash 和 wrist servo 的真实测量，比盲目扩 domain 更关键。

5Structure

joint teacher、finger student、grasp prior 与 residual action 给出正确 inductive bias，减少局部最优。

6Real data

真实 wrist distribution 和少量 on-hardware correction 决定是否能跨过 sim-to-real，而不是 GPU 数量。

一个小型 scaling 实验即可回答“算力是否足够”

训练物体数量取 25% / 50% / 100%，wrist trajectory bank 取 25% / 50% / 100%，同时固定 environment-step budget；再做 50M / 100M / 200M steps 曲线。若数据翻倍只提升 1–3 points，而 oracle gap 或 W0→W1 gap 仍大，继续堆算力不是答案。

推荐的数学主方法候选 asymmetric recurrent actor-critic + goal-conditioned residual action + failure-aware sampler；论文后续可加入 CVaR objective。fragile 版本再引入 constrained RL / CBF。先不要同时上 diffusion、foundation model 和高分辨率触觉，否则无法知道提升来自哪里。

10. 从明天开始的执行清单

  1. 先冻结数据 split：human subject + object instance + wrist performer 同时隔离；禁止 retarget 后再随机切分。
  2. 冻结 current PPO checkpoint，不再调 reward；先补 T0 β=0 与直接 β=1 两个 mismatch 端点。
  3. 做 8–12 物体的 grasp-bank pilot：每个物体 2 modes、每 mode 3–5 goals，分别构建 PH / PR / PM 并固定候选数。
  4. 完成 L20 retarget + hard filter：16 active + 真实 coupling；穿透、关节余量、2 s hold、力/电流和 12-direction wrench。
  5. 建立 100–200 条 wrist test bank：程序化一半、Quest 真实轨迹一半；训练和测试人物/轨迹严格隔离。
  6. 做 L20 tactile audit：型号、shape、timestamp、空载 60 s、已知法向载荷、切向 ramp、step response、饱和与温漂。
  7. 实现 exogenous wrist driver 与 T1：β 从 0 到 1，记录 desired / realized kinematics；β=1 时 PPO loss 只算 finger active dims。
  8. 只用 T1 β=1 rollout 蒸馏 S0，随后在 100% external wrist 下做 S1 on-policy fine-tune；imitation loss 逐步退火。
  9. 实现 tactile ladder，先 contact/netforce → Fn+CoP，不做 dense skin。
  10. 跑 4 prior × 2 endpoints × 3 seeds，同时报告 robustness / naturalness / diversity；通过 pilot gate 后才扩对象与 step budget。
  11. 真实 L20 小规模闭环：10 个对象 × 5 条 wrist traces；记录 sim/real gap，而不是只挑成功视频。
